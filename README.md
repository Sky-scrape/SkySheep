SkySheep 是跑在你自己电脑上的开源 AI Agent 工作台：Python asyncio 引擎 + pywebview 桌面壳 + 零构建前端，MIT 协议。
给它一个任务，它会自己读文件、改代码、跑命令、联网查资料、操作电脑，把多步骤的活做到底。

它和单体 Agent 的差别在两头，这也是这个项目最想解决的两件事。

**一头是「谁来做」**：要紧的判断不必只问一个模型——输入框里能直接切到圆桌（多模型并行作答、主席融成一份答案）、团队（按角色分工、工单板跟进度）、对抗（专门挑错的审查流水线）；另有独立的接力工作台，让主屏与副屏会话按轮交替推进同一件事。

**另一头是「放手之后怎么兜住」**：写文件与执行命令默认先弹确认卡（写文件附 diff 预览），每轮改动自动快照、一键撤销本轮，会话、配置与密钥全部留在本机。

## 🎯 它能接哪些活

先把功能清单放一边，说它具体能接什么活：

**整理文件与文档** —— 「把下载文件夹堆了半年的文件按类型归档重命名」「从几十份 PDF 里抽取关键信息，汇成一张 Excel 对照表」。文件读写与精确编辑、PDF / Word / Excel / PPT / CSV 解析都是内置工具，这类活不用先写脚本，把要求说清楚就行；移动与删除走可回滚的专用操作，误删也能撤。

**在现有项目里干活** —— 读代码、定位问题、改文件、跑测试，一轮做完不满意就「撤销本轮改动」。适合改配置、批量重构、写小工具这类验收标准明确的活。

**把重复劳动变成定时自动化** —— 「每天早上八点抓这几个网站的新内容，汇总后推到飞书群」「每周五下午跑一遍周报汇总」。定时任务负责到点执行，任务编排负责多步依赖与产出传递；导出为 Windows 计划任务后，应用没开着也能到点跑。

**替你操作电脑** —— 截屏、鼠标、键盘、窗口、剪贴板（默认关闭，需要时在设置里开启）。适合「在几个软件里各点一遍导出」这类重复界面操作。

**人不在电脑前也管得住** —— 手机浏览器打开完整界面，确认卡照常逐条弹；飞书 / 微信里发消息派活、收日报与终态通知。

## 👥 三种多模型协作：一轮任务里让模型各管一段

多模型不是「同时开几个窗口问同一个问题」，而是在同一轮任务里让模型各有分工。三种模式在输入框里直接切换，同一轮只能选一种，避免互相打架。

**圆桌 —— 一次提问，多个模型共同作答。** 成员模型并行独立作答，主席（主对话模型）把全部草稿融合成一份最终答案，锋利的批评和稳妥的结论都能留下。成员可套批评者、事实核查员、简洁派、实干者等五种身份预设；可开启辩论轮，让成员互看草稿后再修订一轮；A/B 模式保留各成员原始回答。每份草稿随会话落库，可回看、引用、追问。

**团队 —— 按角色分工，工单板跟进度。** 把一个大任务拆成若干工单，每个队员有自己的角色、模型和工具范围，在团队频道里汇报、被验收、被打回重做。总管分两种：用户总管（你每条消息就是一道指令）与 AI 总管（指定一个模型当总管，自动推进拆解 → 派工 → 收报 → 验收 → 交付，你保留插话、接管、收队三权）。需要几个人碰一下时可开「小会」，讨论只在频道里呈现，不打断主线。防失控上限包括全局轮次上限、重复返工超限强制裁定、成员停滞自动移交总管、Token 预算越线强制交付。

**对抗 —— 专门找错的审查流水线。** 不追求答案好看，追求把问题挖出来：发现 → 调查 → 建议 → 裁判四角色接力，各自只看得到自己该看的那部分。挑出问题的收益高于点头附和（不对称激励），阶段上下文相互隔离，某一环失败按降级路径给出可用结论。适合方案评审、代码审查、合同风险这类「宁可得罪人也要说」的场景。审查报告里认定成立的发现可以勾选，一键登记成指定队员的顾问型工单去核实。

有三件事要先说清楚：

- **权限边界**：圆桌与团队照走各自的权限门，敏感操作该确认还是确认；对抗是纯文本推理，不经权限门，也不会自己动手改东西。
- **成本**：多模型确实比单模型贵。控制线是现成的——圆桌有雷同草稿去重、成员轻上下文、融合预算裁剪等七项 Token 机制；团队有全局轮次上限与预算越线强制交付；成员模型可以各自指定，便宜模型跑成员、强模型当主席或总管。同一服务商的多个成员会共享并发闸，不会用一把 Key 把自己撞出 429。
- **追溯**：圆桌草稿、团队工单与频道消息、对抗各角色输出全部随会话落库，换设备重开也回放得出来。

### 接力工作台：主副屏交替推进

接力适合需要两边来回交接的活（如「出方案 → 执行 → 反馈 → 修订」）。它不是输入框里的第四种协作模式，而是独立工作台：点侧栏「接力」在右侧看板填写总任务与两边每轮的任务，点「执行」让轮到的一方跑完整一轮正常对话（Agent、工具、权限门、检查点全部照常），完成后自动交棒，下一轮带上对方上一轮的输出；可开「连续交替」自动轮流执行。两屏的正文都留在各自会话里。设计见 [docs/接力模式设计.md](docs/接力模式设计.md)。

## 🔒 默认安全：先确认、能回滚、数据不出本机

让 Agent 替你动文件、跑命令，前提是「出了事兜得住」。这些是默认行为，不需要先配置一轮：

- **每一步先确认**：只读操作自动放行；写文件（附 diff 预览）与执行命令默认逐次弹卡确认。三档权限模式（安全执行 / 自动编辑 / 完全访问）可调，放宽档仅限本机界面切换
- **命令白名单**：按完整词前缀匹配，含 shell 拼接或解释器旗标的命令不命中规则、一律重新确认；规则按项目持久化，设置页可管理
- **改动可回滚**：文件改动按轮快照，一键撤销本轮改动，重启后仍可回滚；检查点每会话保留 50 轮，全项目兜底 500 条
- **数据不出本机**：会话、配置与密钥全部存于本机，无遥测；网页抓取仅允许公网 http(s)，具备 SSRF 防护；外部网页 / 文档内容按数据处理，不当作指令执行
- **出错了有得救**：会话库自动滚动备份（保留 20 份）可视化恢复；运行中心能看到每一轮与后台子代理的状态，失败或被重启打断的运行可一键重发/重跑（只有真未跑完的才提供，已完成的不会重放写入类任务）；项目自带的 MCP 与技能配置需先确认信任；诊断包导出自动打码密钥

<details>
<summary><b>细粒度机制</b>（展开）</summary>

- 命令白名单提供整工具 / 词前缀 / 精确参数 / 通配四类规则，解释器 `-c / -e / --eval` 旗标全文扫描，防止借解释器绕过前缀规则；收紧后不再命中的历史规则在设置页标「已失效」徽章（悬停显示原因），便于逐条清理
- 拼接判定按**实际执行的 shell** 来：Windows 走 `cmd.exe`，单引号不算引号、`%VAR%` 会展开成变量值（值里可能带分隔符），两者都算拼接面并回退逐次确认——不用一套 POSIX 引号规则同时套两平台
- 电脑控制按动作收敛：动作白名单只固化确认过的那一次，关闭窗口 / 写剪贴板不整类放行
- `web_fetch` 解析结果固定为连接目标（防 DNS rebinding），重定向逐跳复检
- 远程访问按连接会话隔离：拿到令牌的设备只能看自己当前会话的运行、任务、权限与状态；令牌轮换或关闭远程会主动断开已建立的远程连接。这不是多用户账户隔离——同一令牌的设备可自行切换项目与会话，请只把令牌发给可信设备
- 应用内更新要求发布方提供 `.sha256` 校验附件，缺失即拒绝自动安装（引导手动下载核对）；校验和与安装包同源，只能防传输损坏与单侧篡改，**不证明发布者身份**；更新失败只做到可发现、有备份、可手动恢复，不自动回滚
- 子代理可跑在 git worktree 隔离副本里（独立分支、完成自动提交、合并由主会话决定），把「让它自己改」和「我的工作副本」隔开
- MCP 工具描述限长，防止挤占上下文或夹带注入内容；系统提示词内置提示注入防线，网页 / 文档内容按数据处理

</details>

## ⏰ 不用守着电脑

Agent 的价值在于你不在的时候它也在干活。三件事分别对应「到点自己跑」「跑完告诉你」「你随时能插话」：

- **到点自己跑**：定时任务（周期执行、工具预授权）与日程提醒（周 / 月历视图、提前提醒）；任务编排把多个任务连成 DAG 流水线，上游并行推进、依赖到齐自动接力，失败重试并带上上次失败原因。应用彻底关掉也要到点跑，就把任务导出为 Windows 系统计划任务（`schtasks` 注册，到点以 `skysheep cron run <任务id>` 独立执行）
- **跑完告诉你**：任务与流水线的终态、每日运行日报可推送到飞书 / 微信 / Webhook（Webhook 为纯出站推送，可选 HMAC 签名验源）；自动化页的「今日运行」汇总当天执行情况
- **你随时能插话**：手机浏览器打开完整界面（局域网令牌 + 二维码，或经 Tailscale 跨网络连回），确认卡远程审批；飞书 / 微信渠道里发消息派活、追加指令、接收终态通知

长期记忆也在这一层：项目记忆可在界面内编辑，全局自动记忆会把轮次要点沉淀成待审候选（采纳才写入），会话归档可自动提炼，定期自动整理前先备份；记忆地图给出项目演化时间线、主题关联图谱与 LLM 演化摘要。

## 🧩 扩展走开放标准

扩展点收敛在 MCP、Skills 与 Mods 三个入口上，前端保持零构建、不引入插件 JS API：

- **MCP 客户端**：stdio / Streamable HTTP 双传输，兼容 Claude Desktop 配置，内置结构化思考、网页抓取、时间、Git、文件读写、记忆库、cua 电脑驱动七个预设；服务器崩溃后自动重连，已注册的工具照常可用（失败的调用不重放）
- **Skills 技能包**：全局 / 项目两级作用域；文件夹 / .zip / GitHub·Gitee 链接导入，也可扫描导入本机已有技能；二十个官方场景模板随包内置，一键安装用包内副本、离线可用；`/save-skill` 把当前会话的做法一键存成技能草稿
- **Mods 扩展（实验性）**：内置示例可用 quickjs 沙箱跑，也可切到 Claude Code 插件格式让 Mod 跑在独立 Node 子进程里（同一套插件两边都能跑）。Mod 能增删界面元素（pane / 状态条 / 模态浮层）、注册工具、参与权限决策（只能收紧或显式改写工具参数）；Mod 注册的工具一律按最高风险分级，引擎侧的出站密钥预拒绝、主目录写入确认、递归删除守卫不因 Mod 而放宽
- **网络统一出口**：设置 · 高级 · 网络一页管住整台应用怎么出网——代理、绕行名单（`example.com` / `.example.com` / `*.example.com` / CIDR，写法与 curl 对齐）、自签 CA 证书（追加语义，不打断公网证书链）。模型请求、联网搜索、网页抓取、MCP（远程 HTTP 与 stdio 子进程）、命令子进程、钩子、终端面板与 Mods 的 Node 运行时全部遵循

## 🧭 和终端 Agent 有什么不同

SkySheep 与 Claude Code、OpenAI Codex CLI 这类终端 Agent 的差异不在逐条功能清单，而在产品形态与使用方式——终端工具强在脚本化与 CI 集成，SkySheep 强在「看得见、管得住、够得着」：

- **多模型是原生体验**：圆桌 / 团队 / 对抗三种协作模式在输入框里直接切换，接力工作台从侧栏打开右侧看板（见[上一节](#-三种多模型协作一轮任务里让模型各管一段)）
- **看得见**：完整图形界面、中文优先。对话、确认卡、diff 预览、文件改动、终端输出、审查诊断都在界面里，不用盯终端滚动日志
- **管得住**：权限确认、检查点回滚、工作区信任、命令白名单的交互全部图形化——改了哪个文件、谁发起的、能不能撤销，一眼看清
- **够得着**：人不在电脑前也照常工作。定时任务与依赖编排自动推进，日报与终态推送到飞书 / 微信 / Webhook；手机浏览器远程打开完整界面，确认卡远程审批

反过来，如果你要的是脚本化嵌入 CI、纯键盘效率流，终端 Agent 仍是更顺手的形态；SkySheep 内置 `skysheep run` 无头模式与终端 REPL 作为补充。

SkySheep 是 **Windows 桌面产品**：安装包、桌面壳、DPAPI 凭据加密、Windows 沙箱、窗口与进程管理、`schtasks` 定时导出都只针对 Windows 打磨。`--browser` 模式能在 macOS / Linux 上跑起引擎与网页界面，属于开发者兜底路径，不在支持承诺内。跨平台支持要等 Windows 桌面体验达到稳定标准后再单独评估（见[路线图与非目标](#-路线图与非目标)）。

## 🚀 安装与运行

**安装包（推荐普通用户）**

到 [Releases](https://github.com/Sky-scrape/SkySheep/releases/latest) 下载 `SkySheep-<版本>-setup.exe` 双击安装（Windows 10 / 11 x64）。首次运行如被 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」（未签名程序的默认待遇，详见 [SmartScreen 放行说明](docs/smartscreen-说明.md)）。

**源码运行（开发者）**

源码运行以 Windows 为支持平台；macOS / Linux 上引擎与网页界面（`--browser`）可用，但不承诺桌面壳、凭据加密与系统集成相关能力。

```bash
cd SkySheep/engine
uv sync                          # 安装依赖（Python >= 3.11）
uv run skysheep app              # 桌面应用（--browser 用浏览器打开）
uv run skysheep chat             # 终端交互
uv run skysheep run "任务"       # 无头一次性运行（支持 JSON 输出）
```

**初始配置**

首次启动由配置向导三步完成接入（选服务 → 填 Key → 开始），自动检测本机本地推理服务；没有 API Key 可先进入演示模式，查看一轮真实工具调用的完整过程。

<details>
<summary><b>📦 双击启动 / 打包发布</b>（展开）</summary>

```bash
cd engine
.venv\Scripts\python.exe tools\install_shortcut.py        # 开始菜单/桌面快捷方式（源码版）
.venv\Scripts\python.exe tools\install_shortcut.py --exe  # 指向打包好的 SkySheep.exe
.venv\Scripts\pyinstaller.exe --noconfirm --clean SkySheep.spec   # 产物 dist/SkySheep/SkySheep.exe（PyInstaller 随 uv sync 入册安装）
```

单文件安装包：安装 [Inno Setup 7](https://jrsoftware.org/isdl.php)（6.x 不随编译器分发简体中文消息文件，编译安装包会失败）后执行 `ISCC.exe tools\installer.iss`，产物在 `installer/`；或 `python tools/release.py` 一键完成打包 → 校验 → 冒烟 → 编译安装包（默认只构建不发布，`--upload` 才上传 Release）。

</details>

> **📦 多实例并存**：源码运行默认使用 dev 身份，数据在 `~/.skysheep-dev/`，与安装版的 `~/.skysheep/` 相互隔离、可同时运行；环境变量 `SKYSHEEP_INSTANCE` 可派生更多独立实例。

> **⏰ 定时任务的运行前提**：定时任务与日程提醒由应用内循环触发，仅在 SkySheep 运行期间生效。关窗时选择「缩到系统托盘」即继续后台运行；彻底退出期间到点的任务在下次启动补跑；可在 设置 · 高级 开启「开机自动启动」。应用彻底关闭也要到点跑？在任务卡片上「⊞」导出为 Windows 系统计划任务。

## 📋 功能总览

<summary><b>完整能力清单</b>（展开）</summary>

**多模型协作**

- 圆桌：成员并行作答 + 主席融合；五种成员身份预设（批评者 / 事实核查员 / 简洁派 / 实干者等）；辩论轮与 A/B 模式；草稿随会话落库，可回看、引用、追问；去重与预算裁剪等七项 Token 机制
- 团队：工单板 + 角色分工 + 团队频道；用户总管 / AI 总管（七个内部工具闭环，全只读不经权限门）；「小会」复用圆桌且只在频道呈现；四项防失控上限；团队模板可另存与复用；工单、汇报与频道消息全量落库可回放
- 对抗：发现 → 调查 → 建议 → 裁判四角色流水线，不对称激励 + 阶段上下文隔离 + 失败降级；成立的发现可一键登记为团队顾问型工单（内容取自服务端落库元数据，客户端不能伪造）
- 接力：主副屏交替推进，双表持久化、幂等请求 + 版本 CAS、数据目录独占锁，仅本机可调

**模型与对话**

- 内置 10 家云服务预设（Anthropic / OpenAI / Gemini / xAI / MiniMax / DeepSeek / 智谱 / Kimi / Qwen / 小米 Mimo）+ 自定义中转（含 LM Studio 等本地推理服务）；模型列表与上下文窗口一键探测，能力探测（流式 / 工具 / 图片 / 思考强度）与脱敏诊断报告
- 思考强度按任务自动调档；思考过程流式展示、可折叠回看；审查页「轮次诊断」按会话拆解每轮耗时（工具次数与最慢工具 / 权限等待 / token），「这一轮为什么慢」有处可查
- 上下文自动压缩（CJK 感知估算，触发比例可调；手动 `/compact` 在桌面端输入框可用，CLI 里没有这个命令）
- 每日 Token 预算护栏；用量越过 80% / 100% 两档时各推一条渠道告警（同档每天最多一条；告警跟着渠道走——未启用聊天 / Webhook 渠道就不告警，护栏照常在本应用内拦截）；用量仪表盘按会话 / 服务 / 模型统计，支持费用估算
- 辅助对话可多开独立实例、各自设定模型与历史，不占用主会话；标签可拖动排序、重命名、右键管理
- 提示词库（拼音首字母过滤、AI 润色、导入导出）；`~` 提示词、`/` 命令、`@` 文件引用、`&` 对话引用；语音输入

**任务执行**

- 30 个内置工具：文件读写、精确编辑、目录操作与通配查找、命令执行（支持后台进程管理）、正则搜索、网页抓取与搜索（多服务商）、PDF / Word / Excel / PPT / CSV 读写、图片理解、AI 画图、任务清单、记忆写入、日程写入、技能加载、流水线编排；网页抓取带注入防御——外部内容包进边界框（声明其中的指令不构成用户或系统的指令）、命中注入话术时附提示
- 子代理另有 `spawn_agent` / `check_task` / `wait_task` 三件套：六种内置角色 + 自定义角色（工具范围 / 模型 / 思考强度可配）；后台并行排队；支持 git worktree 隔离派生，独立分支运行、完成自动提交
- 电脑控制与浏览器控制：截屏、鼠标、键盘、窗口、剪贴板、浏览器打开 / 页内自动化（默认关闭，设置内按需开启；证书校验与浏览器数据清理同在「浏览器控制」页）
- 执行 / 规划双模式，任务清单实时同步；任务耗时预估与实测用时记录
- 检查点按轮快照，一键撤销本轮文件改动，重启后仍可回滚

**自动化与记忆**

- 定时任务与日程提醒；任务编排流水线（声明 `all` / `any` 依赖与条件分支、并发上限与节点超时、失败重试带原因、产出摘要注入下游）；可导出为 Windows 系统计划任务；自动化页「今日运行」汇总当天执行

## 🏗 系统架构

```
┌────────────────────────────────────────────┐
│ 桌面壳：pywebview 原生窗口（WebView2）        │
│  └─ 浏览器兜底（--browser）                  │
├────────────────────────────────────────────┤
│ 本地服务层：FastAPI + WebSocket             │
│  └─ JSON-RPC 请求 + AgentEvent 事件流        │
│  └─ 零构建前端（原生 HTML/CSS/JS，静态托管）   │
├────────────────────────────────────────────┤
│ SkySheep Engine (Python 3.11+, asyncio)    │
│  ├─ core/      Agent 循环、事件流、子代理、   │
│  │             压缩、检查点、圆桌/团队/对抗   │
│  ├─ models/    Provider 层（openai/anthropic/fake）│
│  ├─ tools/     内置工具（含 web_fetch）+ Schema 导出│
│  ├─ security/  Permission Gate + 白名单 + 租约│
│  ├─ skills/    Skills 发现/开关/注入/安装      │
│  ├─ mcp/       MCP 客户端（stdio/HTTP）       │
│  ├─ session/   SQLite 持久化 + 全文搜索        │
│  ├─ config.py  ~/.skysheep/config.toml      │
│  └─ cli/       终端 REPL / 桌面启动器         │
└────────────────────────────────────────────┘
```

设计要点：**事件流驱动**——Agent 运行全程建模为 `AgentEvent`，CLI、GUI、WebSocket 消费同一套引擎 API；敏感操作由 `PermissionGate` 产出确认事件并挂起，前端决策后恢复执行。

代码可审计：全部源码（Python 引擎与前端 HTML/CSS/JS）为未混淆的可读代码；`static/vendor/` 下的 mermaid、xterm 等为第三方库的上游构建产物（版本锁定、未经改写）。

## 🗺 路线图与非目标

- ✅ 当前版本 **v2.6.1**：引擎内核 → MCP / 技能生态 → 桌面应用 → 圆桌多模型与任务编排 → 记忆地图 → 多轮审查加固与结构重构 → 会话分屏与对抗性审查 → 运行可靠性与数据生命周期收口 → 触屏滑动导航治理与安全审查整改 → 全局出网设置与协作工作台（逐版明细见 [CHANGELOG.md](CHANGELOG.md)）
- 🚧 **后续方向**：代码签名分发 · Windows 桌面体验与稳定性收口（安装包已签名前的 SmartScreen 拦截指引见 [docs/smartscreen-说明.md](docs/smartscreen-说明.md)）

**非目标**：

- **原生移动 App** —— 桌面壳是权限确认、检查点等安全交互的载体，现阶段不维护独立的移动端安全模型；网页端 PWA 已支持（添加到主屏幕）
- **macOS / Linux 桌面支持（当前阶段）** —— SkySheep 是 Windows 桌面产品，安全模型（DPAPI 凭据加密、Windows 沙箱、窗口与进程管理、`schtasks` 定时）都建立在 Windows 之上。`--browser` 模式能在 macOS / Linux 上跑起引擎与网页界面，是开发者兜底路径，不是受支持的产品形态。只有 Windows 桌面达到稳定标准后才重新评估其他平台；在此之前不为跨平台过早抽象安全模型、窗口管理与安装流程
- **向量记忆 / 多级上下文压缩** —— 现有压缩与归档提炼记忆已覆盖当前场景，不为此扩大安装体积
- **用 ripgrep 替换内置搜索** —— 保持纯 Python 零依赖的「安装即可用」分发形态；不绑定外部二进制，检测到本机 rg 时可选用加速（已实装：模式为纯 ASCII 时自动加速，缺省仍为内置实现）
- **自建插件 JS API** —— 扩展点收敛在 MCP、Skills 与 Mods 三个入口上，前端保持零构建
- **运营型技能广场** —— 技能分发走应用内导入（文件夹 / .zip / 链接），不做集中运营的商店
