SkySheep 是跑在本机的开源 AI Agent 工作台：Python asyncio 引擎 + pywebview 桌面壳 + 零构建前端。
给它一个任务，它会自己读写文件、执行命令、联网检索、操作电脑，并按计划完成多步骤工作；
要紧的事可以让多个模型一起做——输入框里的圆桌并行作答后融合、团队按角色分工、对抗专门挑错，三种协作模式可直接切换；另有独立的接力工作台，让主屏与副屏会话按轮交替推进任务。
写文件、跑命令等敏感操作默认先弹出确认卡片，每轮文件改动自动快照、可一键回滚；会话、配置与密钥全部保存在本机。

## 🎯 它能帮你做什么

不按功能清单介绍，先说它具体能接哪些活：

**整理文件与文档** —— 「把下载文件夹堆了半年的文件按类型归档重命名」「从几十份 PDF 里抽取关键信息，汇成一张 Excel 对照表」。文件读写与精确编辑、PDF / Word / Excel / PPT / CSV 解析都是内置工具，这类活不用先写脚本，把要求说清楚就行；移动与删除走可回滚的专用操作，误删也能撤。

**在现有项目里干活** —— 读代码、定位问题、改文件、跑测试，一轮做完不满意就「撤销本轮改动」。适合改配置、批量重构、写小工具这类验收标准明确的任务。

**把重复劳动变成定时自动化** —— 「每天早上八点抓这几个网站的新内容，汇总后推到飞书群」「每周五下午跑一遍周报汇总」。定时任务与依赖编排负责到点执行和产出传递；导出为 Windows 计划任务后，应用没开着也能到点跑。

**多模型一起会诊** —— 重要的事不放心只问一个模型：圆桌让多个模型各自作答、主席融合成一份答案；团队按角色分工、工单板跟进度；对抗模式组织专门挑错的审查流水线。

**替你操作电脑** —— 截屏、鼠标、键盘、窗口、剪贴板（默认关闭，需要时在设置里开启）。适合「在几个软件里各点一遍导出」这类重复界面操作。

**人不在电脑前也管得住** —— 手机浏览器打开完整界面，确认卡照常逐条弹；飞书 / 微信里发消息派活、收日报与终态通知。

## 👥 一次任务，三种多模型协作方式

多模型不是「同时开几个窗口问同一个问题」，而是在一轮任务里让模型各有分工。三种模式在输入框里直接切换，同一轮只能选一种，避免互相打架；接力工作台从侧栏打开右侧看板。

**圆桌 —— 一次提问，多个模型共同作答**。成员模型并行独立作答，主席（主对话模型）把全部草稿融合成一份最终答案，锋利的批评和稳妥的结论都能留下。成员可套批评者、事实核查员、简洁派、实干者等身份预设，可开启辩论轮让成员互看草稿后再修订一轮；每份草稿随会话落库，可回看、引用、追问。雷同草稿去重、成员使用轻上下文等七项机制用于控制 Token 消耗。

**团队 —— 按角色分工，工单板跟进度**。把一个大任务拆成若干工单，每个队员有自己的角色、模型和工具范围，在团队频道里汇报、被验收、被打回重做。总管分两种：用户总管（你每条消息就是一道指令）与 AI 总管（指定一个模型当总管，自动推进拆解 → 派工 → 收报 → 验收 → 交付，你保留插话、接管、收队三权）。需要几个人碰一下时可开「小会」，讨论只在频道里呈现，不打断主线。防失控上限包括全局轮次上限、重复返工超限强制裁定、成员停滞自动移交总管、Token 预算越线强制交付。

**对抗 —— 专门找错的审查流水线**。不追求答案好看，追求把问题挖出来：发现 → 调查 → 建议 → 裁判四角色接力，各自只看得到自己该看的那部分。挑出问题的收益高于点头附和（不对称激励），阶段上下文相互隔离，某一环失败按降级路径给出可用结论。适合方案评审、代码审查、合同风险这类「宁可得罪人也要说」的场景。

两条边界要说明白：圆桌与团队照走各自的权限门，敏感操作该确认还是确认；对抗是纯文本推理，不经权限门。成本上多模型确实比单模型贵，控制线是现成的——圆桌的七项 Token 机制、团队的全局轮次上限与预算越线强制交付，加上成员模型可以各自指定（便宜模型跑成员，强模型当主席或总管）。

### 右侧工作台：接力

接力适合需要主副屏交替推进的研究或方案：主屏对应当前会话，副屏是接力时打开的独立会话，两边在同一窗口分栏显示，按轮交替执行各自配置的任务。它不是输入框里的第四种协作模式；两边都是完整 Agent 会话，工具、权限确认与检查点照常生效。

## 🔒 为什么可以放心让它动手

让 Agent 替你动文件、跑命令，前提是「出了事兜得住」。安全是默认行为，不需要先配置一轮：

- **每一步先确认**：只读操作自动放行；写文件（附 diff 预览）与执行命令默认逐次弹卡确认。三档权限模式（安全执行 / 自动编辑 / 完全访问）可调，放宽档仅限本机界面切换
- **命令白名单**：按完整词前缀匹配，含 shell 拼接或解释器旗标的命令不命中规则、一律重新确认；规则按项目持久化，设置页可管理
- **改动可回滚**：文件改动按轮快照，一键撤销本轮改动，重启后仍可回滚；检查点每会话保留 50 轮，全项目兜底 500 条
- **数据不出本机**：会话、配置、密钥全部存于本机，无遥测；网页抓取仅允许公网 http(s)，具备 SSRF 防护；外部网页 / 文档内容按数据处理，不当作指令执行
- **出错了有得救**：会话库自动滚动备份（保留 20 份）可视化恢复；运行中心能看到每一轮与后台子代理的状态，失败或被重启打断的运行可一键重发/重跑（只有真未跑完的才提供，已完成的不会重放写入类任务）；项目自带的 MCP 与技能配置需先确认信任；诊断包导出自动打码密钥

<details>
<summary><b>细粒度机制</b>（展开）</summary>

- 命令白名单提供整工具 / 词前缀 / 精确参数 / 通配四类规则，解释器 `-c / -e / --eval` 旗标全文扫描，防止借解释器绕过前缀规则；2.3.0 收紧后不再命中的历史规则在设置页标「已失效」徽章（悬停显示原因），便于逐条清理
- 电脑控制按动作收敛：动作白名单只固化确认过的那一次，关闭窗口 / 写剪贴板不整类放行
- `web_fetch` 解析结果固定为连接目标（防 DNS rebinding），重定向逐跳复检
- 检查点每会话保留 50 轮，全项目兜底 500 条；会话备份保留 20 份，可视化恢复
- 远程访问按连接会话隔离：拿到令牌的设备只能看自己当前会话的运行、任务、权限与状态；令牌轮换或关闭远程会主动断开已建立的远程连接。这不是多用户账户隔离——同一令牌的设备可自行切换项目与会话，请只把令牌发给可信设备
- 应用内更新要求发布方提供 `.sha256` 校验附件，缺失即拒绝自动安装（引导手动下载核对）；校验和与安装包同源，只能防传输损坏与单侧篡改，**不证明发布者身份**；更新失败只做到可发现、有备份、可手动恢复，不自动回滚
- MCP 工具描述限长，防止挤占上下文或夹带注入内容；系统提示词内置提示注入防线，网页 / 文档内容按数据处理

</details>

## 🧭 和终端 Agent 有什么不同

SkySheep 与 Claude Code、OpenAI Codex CLI 这类终端 Agent 的差异不在逐条功能清单，而在产品形态与使用方式——终端工具强在脚本化与 CI 集成，SkySheep 强在「看得见、管得住、够得着」：

- **多模型是原生体验**：圆桌 / 团队 / 对抗三种多模型协作模式在输入框里直接切换；接力工作台从侧栏打开右侧看板（见[上一节](#-一次任务三种多模型协作方式)）
- **看得见**：完整图形界面、中文优先。对话、确认卡、diff 预览、文件改动、终端输出、审查诊断都在界面里，不用盯终端滚动日志
- **管得住**：权限确认、检查点回滚、工作区信任、命令白名单的交互全部图形化——改了哪个文件、谁发起的、能不能撤销，一眼看清
- **够得着**：人不在电脑前也照常工作。定时任务与依赖编排自动推进，日报与终态推送到飞书 / 微信 / Webhook；手机浏览器远程打开完整界面，确认卡远程审批

反过来，如果你要的是脚本化嵌入 CI、纯键盘效率流，终端 Agent 仍是更顺手的形态；SkySheep 内置 `skysheep run` 无头模式与终端 REPL 作为补充。

SkySheep 是 **Windows 桌面产品**：安装包、桌面壳、DPAPI 凭据加密、Windows 沙箱、窗口与进程管理、`schtasks` 定时导出都只针对 Windows 打磨。`--browser` 模式能在 macOS / Linux 上跑起引擎与网页界面，属于开发者兜底路径，不在支持承诺内。跨平台支持要等 Windows 桌面体验达到稳定标准后再单独评估（见[路线图与非目标](#-路线图与非目标)）。

## 🚀 安装与运行

**安装包（推荐普通用户）**

到 [Releases](https://github.com/Sky-scrape/SkySheep/releases/latest) 下载 `SkySheep-<版本>-setup.exe` 双击安装（Windows 10 / 11 x64）。首次运行如被 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」（未签名程序的默认待遇，详见 [SmartScreen 放行说明](docs/smartscreen-说明.md)）。

**源码运行（开发者）**

源码运行以 Windows 为支持平台；macOS / Linux 上引擎与网页界面（`--browser`）可用，但不承诺桌面壳、凭据加密与系统集成相关能力。

```bash
cd SkySheep/engine
uv sync                          # 安装依赖（Python >= 3.11）
uv run skysheep app              # 桌面应用（--browser 用浏览器打开）
uv run skysheep chat             # 终端交互
uv run skysheep run "任务"       # 无头一次性运行（支持 JSON 输出）
```

**初始配置**

首次启动由配置向导三步完成接入（选服务 → 填 Key → 开始），自动检测本机本地推理服务；没有 API Key 可先进入演示模式，查看一轮真实工具调用的完整过程。

</details>

> **📦 多实例并存**：源码运行默认使用 dev 身份，数据在 `~/.skysheep-dev/`，与安装版的 `~/.skysheep/` 相互隔离、可同时运行；环境变量 `SKYSHEEP_INSTANCE` 可派生更多独立实例。

> **⏰ 定时任务的运行前提**：定时任务与日程提醒由应用内循环触发，仅在 SkySheep 运行期间生效。关窗时选择「缩到系统托盘」即继续后台运行；彻底退出期间到点的任务在下次启动补跑；可在 设置 · 高级 开启「开机自动启动」。应用彻底关闭也要到点跑？在任务卡片上「⊞」导出为 Windows 系统计划任务（`schtasks` 按「SkySheep-<任务id>」注册，到点以 `skysheep cron run <任务id>` 独立执行）。

## 🏗 系统架构

```
┌────────────────────────────────────────────┐
│ 桌面壳：pywebview 原生窗口（WebView2）        │
│  └─ 浏览器兜底（--browser）                  │
├────────────────────────────────────────────┤
│ 本地服务层：FastAPI + WebSocket             │
│  └─ JSON-RPC 请求 + AgentEvent 事件流        │
│  └─ 零构建前端（原生 HTML/CSS/JS，静态托管）   │
├────────────────────────────────────────────┤
│ SkySheep Engine (Python 3.11+, asyncio)    │
│  ├─ core/      Agent 循环、事件流、子代理、   │
│  │             压缩、检查点                  │
│  ├─ models/    Provider 层（openai/anthropic/fake）│
│  ├─ tools/     内置工具（含 web_fetch）+ Schema 导出│
│  ├─ security/  Permission Gate + 白名单      │
│  ├─ skills/    Skills 发现/开关/注入/安装      │
│  ├─ mcp/       MCP 客户端（stdio/HTTP）       │
│  ├─ session/   SQLite 持久化 + 全文搜索        │
│  ├─ config.py  ~/.skysheep/config.toml      │
│  └─ cli/       终端 REPL / 桌面启动器         │
└────────────────────────────────────────────┘
```

设计要点：**事件流驱动**——Agent 运行全程建模为 `AgentEvent`，CLI、GUI、WebSocket 消费同一套引擎 API；敏感操作由 `PermissionGate` 产出确认事件并挂起，前端决策后恢复执行。

代码可审计：全部源码（Python 引擎与前端 HTML/CSS/JS）为未混淆的可读代码；`static/vendor/` 下的 mermaid、xterm 等为第三方库的上游构建产物（版本锁定、未经改写）。

## 🗺 路线图与非目标

- ✅ 当前版本 **v2.6.0**：引擎内核 → MCP / 技能生态 → 桌面应用 → 圆桌多模型与任务编排 → 记忆地图 → 多轮审查加固与结构重构 → 会话分屏与对抗性审查 → 运行可靠性与数据生命周期收口 → 触屏滑动导航治理与安全审查整改（逐版明细见 [CHANGELOG.md](CHANGELOG.md)）
- 🚧 **后续方向**：代码签名分发 · Windows 桌面体验与稳定性收口（安装包已签名前的 SmartScreen 拦截指引见 [docs/smartscreen-说明.md](docs/smartscreen-说明.md)）

**非目标**：

- **原生移动 App** —— 桌面壳是权限确认、检查点等安全交互的载体，现阶段不维护独立的移动端安全模型；网页端 PWA 已随 2.5.0 支持（添加到主屏幕）
- **macOS / Linux 桌面支持（当前阶段）** —— SkySheep 是 Windows 桌面产品，安全模型（DPAPI 凭据加密、Windows 沙箱、窗口与进程管理、`schtasks` 定时）都建立在 Windows 之上。`--browser` 模式能在 macOS / Linux 上跑起引擎与网页界面，是开发者兜底路径，不是受支持的产品形态。只有 Windows 桌面达到稳定标准后才重新评估其他平台；在此之前不为跨平台过早抽象安全模型、窗口管理与安装流程
- **向量记忆 / 多级上下文压缩** —— 现有压缩与归档提炼记忆已覆盖当前场景，不为此扩大安装体积
- **用 ripgrep 替换内置搜索** —— 保持纯 Python 零依赖的「安装即可用」分发形态；不绑定外部二进制，检测到本机 rg 时可选用加速（已实装：模式为纯 ASCII 时自动加速，缺省仍为内置实现）
- **自建插件 JS API** —— 扩展点收敛在 MCP 与 Skills 两个开放标准上，前端保持零构建
- **运营型技能广场** —— 技能分发走应用内导入（文件夹 / .zip / 链接），不做集中运营的商店
