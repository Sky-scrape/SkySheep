SkySheep 是跑在你自己电脑上的开源 AI Agent 工作台：Python asyncio 引擎 + pywebview 桌面壳 + 零构建前端，MIT 协议。给它一个任务，它会自己读文件、改代码、跑命令、联网查资料、操作电脑，把多步骤的活做到底。

它和单体 Agent 的差别在两头，这也是这个项目最想解决的两件事。

**一头是「谁来做」**：要紧的判断不必只问一个模型——输入框里能直接切到圆桌（多模型并行作答、主席融成一份答案）、团队（按角色分工、工单板跟进度）、对抗（专门挑错的审查流水线）；另有独立的接力工作台，让主屏与副屏会话按轮交替推进同一件事。

**另一头是「放手之后怎么兜住」**：写文件与执行命令默认先弹确认卡（写文件附 diff 预览），每轮改动自动快照、一键撤销本轮，会话、配置与密钥全部留在本机。

## 🎯 它能接哪些活

先把功能清单放一边，说它具体能接什么活：

**整理文件与文档** —— 「把下载文件夹堆了半年的文件按类型归档重命名」「从几十份 PDF 里抽取关键信息，汇成一张 Excel 对照表」。文件读写与精确编辑、PDF / Word / Excel / PPT / CSV 解析都是内置工具，这类活不用先写脚本，把要求说清楚就行；移动与删除走可回滚的专用操作，误删也能撤。

**在现有项目里干活** —— 读代码、定位问题、改文件、跑测试，一轮做完不满意就「撤销本轮改动」。适合改配置、批量重构、写小工具这类验收标准明确的活。

**把重复劳动变成定时自动化** —— 「每天早上八点抓这几个网站的新内容，汇总后推到飞书群」「每周五下午跑一遍周报汇总」。定时任务负责到点执行，任务编排负责多步依赖与产出传递；导出为 Windows 计划任务后，应用没开着也能到点跑。

**替你操作电脑** —— 截屏、鼠标、键盘、窗口、剪贴板（默认关闭，需要时在设置里开启）。适合「在几个软件里各点一遍导出」这类重复界面操作。

**人不在电脑前也管得住** —— 手机浏览器打开完整界面，确认卡照常逐条弹；飞书 / 微信里发消息派活、收日报与终态通知。

- **协作**：圆桌（并行作答 + 主席融合）· 团队（角色分工 + 工单板 + AI 总管）· 对抗（四角色挑错流水线）· 接力（主副屏交替）

## 🧠 设计理念

### 三栏不是装饰

左边是会话与主要入口，中间是对话，右边是一切的辅助：文件、浏览器、审查、任务、日程、自动化、项目记忆、记忆地图、接力、MCP 与技能。之所以把辅助区做成一整块可切页签的面板，而不是散在对话里的浮窗，是因为 Agent 干活时最缺的不是提示，而是把「它正在动什么、动到哪一步」摊在同一屏里；底部再挂一个多标签终端（Ctrl+\`），命令跑起来不用切窗口。

### 更聪明的 Agent 靠更好的上下文

上下文一乱，再强的模型也只能猜。所以项目、会话、记忆、技能这四样是分开管、按需注入的：项目绑定工作目录，子代理、流水线、技能与 MCP 都跟着项目走；一个会话只负责一件具体的事；记忆分项目记忆与全局记忆，超长的部分按本轮相关性挑选注入；技能只在需要时把正文交给模型（上限 20000 字符）。分区干净，模型看到的就是该看的那部分。

### 每一步都看得见、管得住、撤得回

Agent 替你动文件和命令，前提是出了事兜得住。所以权限确认、diff 预览、命令白名单、改动快照全是默认行为而不是可选项：只读自动放行，写与执行逐次确认，每轮改动按轮快照可一键撤销，两个并行任务写同一个文件时先领写租约再动手。

### 要紧的判断，不该只问一个模型

单模型的答案再流畅也只是一个视角。圆桌让多个模型各自作答再由主席融合，团队让角色之间互相验收，对抗专门安排一环来挑错。多花的钱和时间是可控的——成员模型可以各自指定（便宜模型跑成员、强模型当主席），加上预算护栏、轮次上限与草稿去重。

## 👥 多模型协作：一轮任务里让模型各管一段

多模型不是「同时开几个窗口问同一个问题」，而是在同一轮任务里让模型各有分工。三种模式在输入框里直接切换，同一轮只能选一种，避免互相打架。

| | 圆桌 | 团队 | 对抗 |
|---|---|---|---|
| 谁在说话 | 成员模型并行独立作答，主席融合成一份 | 总管派工，队员按角色在频道汇报 | 发现 → 调查 → 建议 → 裁判，四人接力 |
| 适合的活 | 想要一份更全面、更少盲区的答案 | 大任务要拆开做、要跟进度 | 方案 / 代码 / 合同这类要挑错的审查 |
| 怎么收敛 | 全部草稿融合成一份最终答案 | 逐条验收，通过或打回重做 | 裁判裁定，成立的发现转成待核工单 |
| 成本控制 | 去重、轻上下文、融合预算等七项 Token 机制 | 全局轮次上限 + 预算越线强制交付 | 四阶段串行接力，用时间换彻底 |
| 权限边界 | 照走自己的权限门 | 照走自己的权限门 | 纯文本推理，不经权限门 |

**圆桌 —— 一次提问，多个模型共同作答。** 成员并行独立作答，主席（主对话模型）把全部草稿融合成一份最终答案，锋利的批评和稳妥的结论都能留下。成员可套批评者、事实核查员、简洁派、实干者等五种身份预设；可开启辩论轮，让成员互看草稿后再修订一轮；A/B 模式保留各成员原始回答。每份草稿随会话落库，可回看、引用、追问。

**团队 —— 按角色分工，工单板跟进度。** 把一个大任务拆成若干工单，每个队员有自己的角色、模型和工具范围，在团队频道里汇报、被验收、被打回重做。总管分两种：用户总管（你每条消息就是一道指令）与 AI 总管（指定一个模型当总管，自动推进拆解 → 派工 → 收报 → 验收 → 交付，你保留插话、接管、收队三权）。需要几个人碰一下时可开「小会」，讨论只在频道里呈现，不打断主线。防失控上限包括全局轮次上限、重复返工超限强制裁定、成员停滞自动移交总管、Token 预算越线强制交付。

**对抗 —— 专门找错的审查流水线。** 不追求答案好看，追求把问题挖出来：四个角色各自只看得到自己该看的那部分。挑出问题的收益高于点头附和（不对称激励），阶段上下文相互隔离，某一环失败按降级路径给出可用结论。审查报告里认定成立的发现可以勾选，一键登记成指定队员的顾问型工单去核实。

还有一处容易误解：接力（Relay）不在这个三选一里，它是独立工作台，适合「出方案 → 执行 → 反馈 → 修订」这类需要两边来回交接的活。点侧栏「接力」在右侧看板填写总任务与两边每轮的任务，点「执行」让轮到的一方跑完整一轮正常对话（Agent、工具、权限门、检查点全部照常），完成后自动交棒，下一轮带上对方上一轮的输出；可开「连续交替」自动轮流执行。两屏的正文都留在各自会话里。设计见 [docs/接力模式设计.md](docs/接力模式设计.md)。

## 🔍 功能详解

### 一条消息里的完整过程

![对话消息与操作区](docs/images/message-ops.webp)

你说一句「把会议纪要整理成 meeting-notes.md 存到工作目录」，中间其实发生了一串事：模型决定调用 `write_file` → 权限门按当前档位判定 → 确认卡给出 diff 预览 → 落盘 → 对话底部汇总「本轮改动 1 个文件」，旁边就是「撤销本轮改动」。工具调用的耗时、diff、改动清单都不用你去日志里翻。想更省事，把权限档切到「自动编辑」，工作目录内的写入就不再逐次问，但工作目录之外照旧拦下来。

### 模型、用量与成本

| 内置预设填入 Key 即可接入 | 用量与费用按会话可查 |
|:---:|:---:|
| ![模型服务设置](docs/images/providers.png) | ![用量仪表盘](docs/images/usage.png) |

内置十家云服务预设（Anthropic / OpenAI / Gemini / xAI / MiniMax / DeepSeek / 智谱 / Kimi / Qwen / 小米 Mimo），也可以接自定义中转或本机推理服务（LM Studio、Ollama）。模型列表、上下文窗口与能力（流式 / 工具 / 图片 / 思考强度）一键探测，另有一份脱敏诊断报告。用量按会话 / 服务 / 模型统计并估算费用，每日预算护栏越过 80% / 100% 时各推一条渠道告警。思考强度默认按任务自动调档；想看「这一轮为什么慢」，审查页的轮次诊断会拆出工具次数与最慢工具、权限等待、token。

### 定时任务与日程

![日程周历](docs/images/agenda.png)

定时任务支持单次、周期与复杂周期（比如「工作日 10:00–12:00 每 20 分钟一次」），并可预授权工具，减少无人值守时的确认打断；日程提醒带周 / 月历视图与提前提醒。跑完的终态与每日日报可以推到飞书 / 微信 / Webhook。有一点得说明白：应用内触发的任务只在 SkySheep 运行期间生效，关窗时选「缩到系统托盘」就继续后台跑，彻底退出期间到点的任务下次启动补跑；要连应用都没开着也到点跑，就在任务卡片上「⊞」导出成 Windows 系统计划任务。

### 记忆与归档

项目记忆可以在界面里直接编辑；全局自动记忆会把轮次要点沉淀成待审候选，你采纳才写入；会话归档时可自动提炼，定期整理前先备份。记忆地图给出项目演化时间线、主题关联图谱与 LLM 演化摘要。会话多了也不会乱：归档按项目分组管理，可搜索、可按时间或标题排序，也可以设一个保留时长让超期会话自动收进归档（只改标记、不删数据，随时能恢复）。

### 扩展：MCP / Skills / Mods

扩展点收敛在三个入口上，前端保持零构建、不做自建插件 JS API：**MCP** 支持 stdio 与 Streamable HTTP、兼容 Claude Desktop 配置、内置七个预设，服务器崩了自动重连且已注册的工具照常可用；**Skills** 分全局 / 项目两级，可从文件夹、.zip 或 GitHub·Gitee 链接导入，二十个官方场景模板随包内置，`/save-skill` 能把刚做完的流程存成技能草稿；**Mods**（实验性）可以跑在 quickjs 沙箱里，也可以切到 Claude Code 插件格式跑在独立 Node 子进程里——同一套插件两边都能跑。另外整台应用怎么出网由 设置 · 高级 · 网络 一处决定：代理、绕行名单（curl 写法，支持 `*.example.com` 与 CIDR）、自签 CA 证书（追加语义，不打断公网证书链），模型请求、联网搜索、网页抓取、MCP、命令子进程、终端面板与 Mods 的 Node 运行时都遵循。

## 🔒 为什么可以放心让它动手

安全是默认行为，不需要先配置一轮：

- **每一步先确认**：只读操作自动放行；写文件（附 diff 预览）与执行命令默认逐次弹卡确认。三档权限模式（安全执行 / 自动编辑 / 完全访问）可调，放宽档仅限本机界面切换
- **命令白名单**：按完整词前缀匹配，含 shell 拼接或解释器旗标的命令不命中规则、一律重新确认；规则按项目持久化，设置页可管理
- **改动可回滚**：文件改动按轮快照，一键撤销本轮改动，重启后仍可回滚；检查点每会话保留 50 轮，全项目兜底 500 条
- **数据不出本机**：会话、配置与密钥全部存于本机，无遥测；网页抓取仅允许公网 http(s)，具备 SSRF 防护；外部网页 / 文档内容按数据处理，不当作指令执行
- **出错了有得救**：会话库自动滚动备份（保留 20 份）可视化恢复；运行中心能看到每一轮与后台子代理的状态，失败或被重启打断的运行可一键重发/重跑（只有真未跑完的才提供，已完成的不会重放写入类任务）；项目自带的 MCP 与技能配置需先确认信任；诊断包导出自动打码密钥

<summary><b>细粒度机制</b>（展开）</summary>

- 命令白名单提供整工具 / 词前缀 / 精确参数 / 通配四类规则，解释器 `-c / -e / --eval` 旗标全文扫描，防止借解释器绕过前缀规则；收紧后不再命中的历史规则在设置页标「已失效」徽章（悬停显示原因），便于逐条清理
- 拼接判定按**实际执行的 shell** 来：Windows 走 `cmd.exe`，单引号不算引号、`%VAR%` 会展开成变量值（值里可能带分隔符），两者都算拼接面并回退逐次确认——不用一套 POSIX 引号规则同时套两平台
- 电脑控制按动作收敛：动作白名单只固化确认过的那一次，关闭窗口 / 写剪贴板不整类放行
- `web_fetch` 解析结果固定为连接目标（防 DNS rebinding），重定向逐跳复检
- 远程访问按连接会话隔离：拿到令牌的设备只能看自己当前会话的运行、任务、权限与状态；令牌轮换或关闭远程会主动断开已建立的远程连接。这不是多用户账户隔离——同一令牌的设备可自行切换项目与会话，请只把令牌发给可信设备
- 应用内更新要求发布方提供 `.sha256` 校验附件，缺失即拒绝自动安装（引导手动下载核对）；校验和与安装包同源，只能防传输损坏与单侧篡改，**不证明发布者身份**；更新失败只做到可发现、有备份、可手动恢复，不自动回滚
- 子代理可跑在 git worktree 隔离副本里（独立分支、完成自动提交、合并由主会话决定），把「让它自己改」和「我的工作副本」隔开
- MCP 工具描述限长，防止挤占上下文或夹带注入内容；系统提示词内置提示注入防线，网页 / 文档内容按数据处理

## 🧭 和终端 Agent 有什么不同

Claude Code、OpenAI Codex CLI 这类终端 Agent 强在脚本化与 CI 集成；SkySheep 把同一类能力放进图形界面，并把多模型协作做成原生交互。

| 维度 | 终端 Agent | SkySheep |
|---|---|---|
| 交互形态 | 终端里的命令行流，适合脚本与 CI | 图形界面、中文优先，确认卡 / diff / 面板都在界面上 |
| 多模型 | 通常一个模型走到底 | 圆桌 / 团队 / 对抗 + 接力工作台 |
| 权限确认 | 命令行参数与规则文件 | 图形化三档权限 + 逐次确认卡 + 项目级命令白名单 |
| 改动回滚 | 靠 git 自己兜 | 按轮快照一键撤销，重启后仍可回滚 |
| 无人值守 | 要自己编排调度 | 定时任务 / 依赖流水线 / 系统计划任务 / 渠道日报 |
| 扩展方式 | 插件与脚本生态 | MCP + Skills + Mods 三个入口，前端零构建 |
| 运行平台 | macOS / Linux 等平台原生 | Windows 桌面产品 |

反过来，如果你要的是脚本化嵌入 CI、纯键盘效率流，终端 Agent 仍是更顺手的形态；SkySheep 内置 `skysheep run` 无头模式与终端 REPL 作为补充。

SkySheep 是 **Windows 桌面产品**：安装包、桌面壳、DPAPI 凭据加密、Windows 沙箱、窗口与进程管理、`schtasks` 定时导出都只针对 Windows 打磨。`--browser` 模式能在 macOS / Linux 上跑起引擎与网页界面，属于开发者兜底路径，不在支持承诺内（见[路线图与非目标](#-路线图与非目标)）。

## 🚀 安装与运行

**安装包（推荐普通用户）**

到 [Releases](https://github.com/Sky-scrape/SkySheep/releases/latest) 下载 `SkySheep-<版本>-setup.exe` 双击安装（Windows 10 / 11 x64）。首次运行如被 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」（未签名程序的默认待遇，详见 [SmartScreen 放行说明](docs/smartscreen-说明.md)）。

**源码运行（开发者）**

源码运行以 Windows 为支持平台；macOS / Linux 上引擎与网页界面（`--browser`）可用，但不承诺桌面壳、凭据加密与系统集成相关能力。

```bash
cd SkySheep/engine
uv sync                          # 安装依赖（Python >= 3.11）
uv run skysheep app              # 桌面应用（--browser 用浏览器打开）
uv run skysheep chat             # 终端交互
uv run skysheep run "任务"       # 无头一次性运行（支持 JSON 输出）
```

**初始配置**

首次启动由配置向导三步完成接入（选服务 → 填 Key → 开始），自动检测本机本地推理服务；没有 API Key 可先进入演示模式，查看一轮真实工具调用的完整过程。

## 🏗 系统架构

```
┌────────────────────────────────────────────┐
│ 桌面壳：pywebview 原生窗口（WebView2）        │
│  └─ 浏览器兜底（--browser）                  │
├────────────────────────────────────────────┤
│ 本地服务层：FastAPI + WebSocket             │
│  └─ JSON-RPC 请求 + AgentEvent 事件流        │
│  └─ 零构建前端（原生 HTML/CSS/JS，静态托管）   │
├────────────────────────────────────────────┤
│ SkySheep Engine (Python 3.11+, asyncio)    │
│  ├─ core/      Agent 循环、事件流、子代理、   │
│  │             压缩、检查点、圆桌/团队/对抗   │
│  ├─ models/    Provider 层（openai/anthropic/fake）│
│  ├─ tools/     内置工具（含 web_fetch）+ Schema 导出│
│  ├─ security/  Permission Gate + 白名单 + 租约│
│  ├─ skills/    Skills 发现/开关/注入/安装      │
│  ├─ mcp/       MCP 客户端（stdio/HTTP）       │
│  ├─ session/   SQLite 持久化 + 全文搜索        │
│  ├─ config.py  ~/.skysheep/config.toml      │
│  └─ cli/       终端 REPL / 桌面启动器         │
└────────────────────────────────────────────┘
```

设计要点：**事件流驱动**——Agent 运行全程建模为 `AgentEvent`，CLI、GUI、WebSocket 消费同一套引擎 API；敏感操作由 `PermissionGate` 产出确认事件并挂起，前端决策后恢复执行。

代码可审计：全部源码（Python 引擎与前端 HTML/CSS/JS）为未混淆的可读代码；`static/vendor/` 下的 mermaid、xterm 等为第三方库的上游构建产物（版本锁定、未经改写）。

## 🤝 开发与贡献

欢迎修 Bug、补文档、加测试、完善体验，也欢迎围绕真实场景提交新的技能包与 MCP 配置。提交 PR 前建议先确认：

- 环境用 `uv`（Python >= 3.11）；前端保持零构建，直接改 `engine/src/skysheep/server/static/`，不引入 Node / npm 工具链
- 提交前跑 `uv run pytest`（`-m "not e2e"` 跳过真实 socket 用例，`-m eval` 跑行为级评测基线）与 `uv run ruff check .`
- 加一个功能通常要走四处：`server/backend.py` 实现 + `server/app.py` 的 `dispatch()` 分支 + `static/index.html` + `static/app.js`（设置页另有约定，配置读写走 `config.py` 的 `_read_raw_config` / `_write_raw_config`）
- 新工具必须在 `Tool` 上声明 `safety`，并显式声明 MCP 四注解；凡涉及写文件或执行命令，必须走 `PermissionGate`，这是不可绕过的
- 文本读写一律走 `textio.py`（编码与行尾符安全），文件移动 / 删除 / 建目录用专用工具（可回滚），不要教 Agent 用 `run_command` 里的 `mv` / `rm` / `mkdir`
- 新增可合并的流式事件类型时同步更新 `_MERGEABLE_DELTA_KINDS`，并保证轮末、异常、取消三条路径都 flush
- 版本号六处一致由 `engine/tools/check_versions.py` 机械校验，`uv.lock` 那处由 `uv sync --locked` 兜住
- 打包与打包冒烟直接用 `.venv` 里的可执行文件，不要经 `uv run`

安全漏洞请通过 [SECURITY.md](SECURITY.md) 的私密渠道报告，不要开公开 issue；其余协作细节见 [CONTRIBUTING.md](CONTRIBUTING.md)，行为准则见 [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)。遇到问题可通过应用内 设置 · 关于 →「💬 反馈问题」导出脱敏诊断包并直达反馈页。

## 🗺 路线图与非目标

- ✅ 当前版本 **v2.6.1**：引擎内核 → MCP / 技能生态 → 桌面应用 → 圆桌多模型与任务编排 → 记忆地图 → 多轮审查加固与结构重构 → 会话分屏与对抗性审查 → 运行可靠性与数据生命周期收口 → 触屏滑动导航治理与安全审查整改 → 全局出网设置与协作工作台（逐版明细见 [CHANGELOG.md](CHANGELOG.md)）
- 🚧 **后续方向**：代码签名分发 · Windows 桌面体验与稳定性收口（安装包已签名前的 SmartScreen 拦截指引见 [docs/smartscreen-说明.md](docs/smartscreen-说明.md)）

**非目标**：

- **原生移动 App** —— 桌面壳是权限确认、检查点等安全交互的载体，现阶段不维护独立的移动端安全模型；网页端 PWA 已支持（添加到主屏幕）
- **macOS / Linux 桌面支持（当前阶段）** —— SkySheep 是 Windows 桌面产品，安全模型（DPAPI 凭据加密、Windows 沙箱、窗口与进程管理、`schtasks` 定时）都建立在 Windows 之上。`--browser` 模式能在 macOS / Linux 上跑起引擎与网页界面，是开发者兜底路径，不是受支持的产品形态。只有 Windows 桌面达到稳定标准后才重新评估其他平台
- **向量记忆 / 多级上下文压缩** —— 现有压缩与归档提炼记忆已覆盖当前场景，不为此扩大安装体积
- **用 ripgrep 替换内置搜索** —— 保持纯 Python 零依赖的「安装即可用」分发形态；不绑定外部二进制，检测到本机 rg 时可选用加速
- **自建插件 JS API** —— 扩展点收敛在 MCP、Skills 与 Mods 三个入口上，前端保持零构建
- **运营型技能广场** —— 技能分发走应用内导入（文件夹 / .zip / 链接），不做集中运营的商店
