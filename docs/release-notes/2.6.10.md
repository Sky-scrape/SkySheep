# SkySheep v2.6.10 · 自己的资料也能查，设置补齐一档

![SkySheep](https://sheepsky.com/docs/images/banner.png)

这版把「查资料」补上了：项目里的手册可以建本地索引、按问题检索，联网读过的页面在回答下方给出可点开的来源；同时把设置页缺的 11 项补齐，顺手修了几处实际使用中碰到的毛病。

## 这版你能感觉到什么

- **项目资料可检索**：把项目里的 PDF / Word / Excel / PPT / Markdown 建成索引后，直接用问题检索，返回最相关的几块并标出文件名与页码，长手册不必整本塞进上下文；索引只落在项目自己的 `.skysheep` 目录里，源文件改过自动标失效、增量更新。本机有 Ollama 时再叠加向量、走混合检索，没有则纯中文关键词，照样可用。
- **回答能看出处**：`web_fetch` / `web_search` 本轮读过的网页会分配 `[来源 N]` 编号，最终回答下方列成一行可点开的来源 chip（域名 + 悬停看完整 URL），刷新或重开会话仍在，点开走系统浏览器。
- **项目移除可恢复，常用指令少打字**：设置新增「项目」页，移除只做标记，会话、白名单与自动化全部保留，可随时恢复或彻底删除，还能按「30 天无活动 / 无会话」筛出闲置项目；提示词片段可设 `/review` 这类 ASCII 别名，输入即插入。
- **设置补齐一档**：终端可选 PowerShell / cmd / Git Bash / WSL、可改字体字号；代码块有独立浅 / 深两套配色（GitHub / Solarized / One）、字号、行号与长行换行开关；另有全局自定义指令、阻止空闲睡眠、关闭到托盘、自动下载更新、引导模式与消息流显示开关。

## 怎么装

Windows 10 / 11 x64。安装包 `SkySheep-2.6.10-setup.exe`，未签名。
首次运行如遇 SmartScreen：点「更多信息 → 仍要运行」，详见 [SmartScreen 说明](https://github.com/sky-scrape/SkySheep/blob/main/docs/smartscreen-%E8%AF%B4%E6%98%8E.md)。
sha256：`4686fdb2c921a1727458ac3ac1252389e408fe7042cb30d3502e30a75ffbf26d`

覆盖安装即可；会话、配置与密钥在 `~/.skysheep/` 不动，检查点与历史照常保留。

<summary>工程细节与边界（12 条）</summary>

- **文档索引**：`index_documents` / `search_documents` 按 `--- 第 N 页 ---` 切页、800 字 / 100 重叠分块，落 `<项目>/.skysheep/doc-index.sqlite3`（增量、size + mtime 判失效）；建索引是写操作走权限门，检索只读；索引不进会话库，避免把滚动备份撑大。
- **引用溯源**：同一 URL 复用编号、上限 20，编号随工具结果进上下文、整张表挂在最终消息的 `sources` 字段随消息 JSON 落库；`ToolContext.sources` 为 None 时工具零标注，测试与子代理路径行为不变。
- **混合检索**：记忆排序在有 Ollama 时改为 BM25（精确编号、术语）与嵌入余弦（同义改写）各 0.5 加权；无 Ollama 的回落路径逐字节不变，且不做设置项。
- **评测指标化**：每条用例自动记录结果与耗时，场景可附 token / 工具次数与耗时 / 确认次数 / 重试；运行结束写 `evals/.metrics/last-run.json(l)`，`tools/eval_report.py` 出 Markdown / JSON 报表；`evals/judge.py` 需真实模型，不进默认回归。
- **项目软移除**：只打 `removed_at` 标记（库版本 13），会话、白名单与自动化全部保留；管理页给出会话数、最后活动时间与闲置提示，支持恢复与彻底删除。
- **片段斜杠命令**：`snippets.slash` 存 ASCII 别名，内置命令名与重复别名在保存时拒绝；导出 / 导入一并带上。
- **终端与代码外观**：`ui.json` 的 `term_shell` 只影响新开 / 重启的标签，字体与字号即时应用到已开标签；代码配色与浅深主题解耦，设置 · 界面与通知新增「代码外观」二级页与浅 / 深双预览。
- **全局自定义指令**：`~/.skysheep/instructions.md` 每轮注入系统提示词，与项目 `AGENTS.md`、全局记忆分开，最多 8000 字，设置 · 记忆页可直接编辑。
- **保持电脑运行 / 关闭到托盘**：Windows `SetThreadExecutionState`，退出时清理；托盘不可用时仍退回三选一。
- **自动下载更新**：发现新版本后后台下载并核对校验和，安装仍需用户点「退出并安装」，不静默重启。
- **引导模式**：运行中发消息可注入当前轮，在下一次模型调用前生效；圆桌 / 团队 / 对抗轮自动回落到排队。
- **修复**：接力核验改用与复述请求同一份交接上下文、跑满迭代上限按 `stop_reason` 保留最后一条非空正文；Agent 执行命令统一带 `CREATE_NO_WINDOW` 不再弹黑窗口；团队协作四处实测回归修复（模板不再吞显式 AI 总管、`team=true` 直发消费 grant、排队状态按会话广播、自动池按「服务 × 模型」展开）；帮助的快捷键清单与实现对齐；发版流水线上传前按实际产物改正正文 sha256。
