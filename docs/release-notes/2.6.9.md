# SkySheep v2.6.9 · 官网重做，日常操作更安静

![SkySheep](https://sheepsky.com/docs/images/banner.png)

这版把官网和对外说明重做了一遍，另修了几处日常操作里的小别扭；产品能力本身没有变化。

## 这版你能感觉到什么

- **官网重做**：首屏直接讲清「让 AI 不再单打独斗」，协作（圆桌 / 团队 / 对抗）与接力拆成两条并列的线，协作卡与接力卡换成真实界面的无声循环短片，浅色文字的对比度也一并抬到 AA。
- **加自定义模型服务少一步**：点「检测并获取模型」后，勾选任意一个模型就能保存——第一个勾选的自动成为当前模型，不必再手填模型名；搜索筛选过也不会丢勾选。
- **接力副屏跟着主屏改名**：副屏会话标题从固定的「接力 · 副屏」变成「主屏名 · 副屏」，主屏改名或首轮自动标题落地后自动对齐，分屏列头与接力看板即时同步。
- **日常操作更安静**：保存 / 恢复 / 删除 / 置顶 / 切换模型不再弹「✓ 已保存」式的提示，列表与状态的变化本身就是确认；子代理的「使用模型」也换成与主 / 辅模型同款的纸面弹层。

## 怎么装

Windows 10 / 11 x64。安装包 `SkySheep-2.6.9-setup.exe`，未签名。
首次运行如遇 SmartScreen：点「更多信息 → 仍要运行」，详见 [SmartScreen 说明](https://github.com/sky-scrape/SkySheep/blob/main/docs/smartscreen-%E8%AF%B4%E6%98%8E.md)。
sha256：`54d5ea07751250869ff5be7df5e26ddb19dd1f28ed0990fea1eb4b178023e320`

## 升级说明

覆盖安装即可；会话、配置与密钥在 `~/.skysheep/` 不动，检查点与历史照常保留。
