# SkySheep v2.7.4 · 每个动作都有回执，动效有来有去

![SkySheep](https://sheepsky.com/docs/images/banner.png)

这一版没有新功能清单，做的是把已有的一百多处交互按同一句话重审了一遍：**能让系统判断的，不要留给用户**。落到界面上是三件事——按下去有回执、动效有来有去、会丢东西的动作多一步距离。

## 这版你能感觉到什么

- **停止键回到手边，按下去有回执**：运行中的停止键从顶栏挪到发送键左侧，离输入框一步之遥；点下立刻变「正在停止…」并禁用，不会因为连点发出第二个决策；这一轮刚好已经结束会说明「这一轮已经结束」，请求失败也说原因。输入方式设为「引导」时发送键写「引导」而不是「排队」，不会让人以为要等下一轮。点过停止之后，流式光标不再闪、宠物不再撒花——不再假装还在写、也不再对着半截回答道喜。
- **权限确认：出现和收起都有过渡，点下就不容反悔**：确认条以前硬显示、硬消失，展开时聊天区被瞬间顶上去；现在平滑展开与收起，长命令在条内滚动，只有你本来就在看最新内容时才把视图带到它面前，往上翻旧消息不会被拽回底部。点下允许 / 总是允许 / 拒绝后三键立即禁用、被点那颗写「已提交…」，等后端确认再收卡；出错会复原并说原因。
- **全站动效收成一套语言，关掉也有交代**：以前各组件的时长和曲线各写各的，而且普遍「打开有动画、关掉瞬间消失」。现在统一四条曲线（进场快起慢停、退场慢起快走、颜色与折叠中段对称、落位回弹只给开关与宠物）与四档时长，弹层与遮罩、菜单、通知、命令面板、右面板抽屉、工具卡、团队卡、原生折叠、开关滑块都改成双向过渡；设置子页切换是旧页先淡出、退场结束再淡入。系统「减少动态效果」收束到一处总闸，页面内的平滑滚动也跟随系统设置。右面板拖动调宽重新跟手（此前最多落后指针 108px）。
- **会丢东西的动作多一步距离**：删除、清空、移除、撤销信任这类确认的确定键标红、默认焦点放在取消，误按回车不会删；项目行的 ✕ 明确写成「彻底删除项目（含 N 个会话）」，并指回设置页那个可恢复的「移除」；已归档会话的「全部删除」跟随当前筛选，只删你看见的那些。
- **少问、少填、少跳**：会话搜索同时查标题与消息并跨所有项目，点开即退出搜索；没有配 API Key 的服务，切换按钮直接禁用并说明先填 Key；模型服务有未保存改动时切换会先问（可保存后再切）；子代理总开关拨一下就保存；MCP 导入遇同名服务自动勾上「覆盖」并保留弹窗；协作模板切类型不再把每个角色的需求清空；定时任务那一行直接显示「运行中 · 已跑 mm:ss」并能就地停掉。

## 怎么装

Windows 10 / 11 x64。安装包 `SkySheep-2.7.4-setup.exe`，未签名。
首次运行如遇 SmartScreen：点「更多信息 → 仍要运行」，详见 [SmartScreen 说明](https://github.com/sky-scrape/SkySheep/blob/main/docs/smartscreen-%E8%AF%B4%E6%98%8E.md)。

## 升级说明

覆盖安装即可；会话、配置与密钥在 `~/.skysheep/` 不动，检查点与历史照常保留。没有配置变更，也没有需要手动迁移的步骤。运行中心的旧记录里若还留着「已完成 · 正在执行 X」的旧文案，那是升级前写入的历史条目，新的一轮起不再出现。

<summary>工程细节与边界（9 条）</summary>

- **动效语言定稿**：四条语义曲线（`--ease-out` 进场 / `--ease-in` 退场 / `--ease-std` 对称 / `--ease-pop` 落位）加四档时长，另有循环、骨架、注意力三档专用周期与宠物角色动画一组；组件一律引用 token，`app.css` 125 处 transition 里裸 easing 归零（由脚本每次发布前自查大括号配平与裸 easing 数量）。
- **主题切换整页过渡**：切主题时给根元素挂 240ms 的过渡窗口，只让承载大面积的十几层容器过渡颜色类属性，并用一层旧地面快照（`z-index:-1`）补上不可插值的渐变底；不给 `body *` 挂过渡——设置页实测会新建 288 条过渡、首帧要等 0.6 秒才画出来。窗口一过即摘除。
- **拖动跟手**：分隔线轴向改按 key 后缀（`*_w` 横向 / `*_h` 纵向）派生，不再手抄键名清单；此前 `right_w` 被误判成纵向，关过渡的规则没命中，右面板带着 200ms width 过渡追指针。
- **停止路径与落库口径对齐**：前端在 `queue_updated(pending=0)` 时就地定稿、补「…（已停止）」并摘掉流式态，与引擎 `_persist_partial_stream_text` 写进历史的那句话逐字一致；宠物只在正常完成时撒花。
- **运行中心终态**：`RunCenter.update()` / `cancel()` 在「运行态 → 终态」这一跳清空过程文案，装载旧快照时也做一次清洗（`interrupted` 的说明文案保留）；本轮只保证新记录，旧 `runs.json` 不迁移。
- **定时任务运行态**：`cron_list` 附带按 `task_id` 归一后的 `running_run_id` / `running_since`（账本读失败只降级为「都不在跑」）；前端每秒只改那一行的时间文字，面板没打开不跳秒，叫停走 `factory.cancel(task_id)`。
- **权限决策防重复**：点击立即禁用三键并写「已提交…」，`delivered === false` 收死卡并提示，请求抛错复原三键；卡片展开用 `.open` 类配合先摘 `hidden`、强制一帧再加类，`max-height` 走过渡，收起动画结束后才落 `hidden`。
- **可访问性**：设置导航补 `tabIndex` / `role=button` 与 Enter / 空格触发（输入法组字中不触发），收起后的浮层把内部按钮请出 Tab 序与读屏树；全局快捷键的 Esc 与回车都补了 `isComposing` / 229 判定，中文输入法组字中不再误停正在跑的一轮。
- **验证**：`ruff` 全绿；`pytest -m "not e2e and not eval"` 4400 passed / 11 skipped；`pytest -m e2e` 50 passed（含真实 Chromium 的骨架、回车发送、权限卡允许后撤销、390px 无横向溢出三条验收）；390×844 与 1440×900 两档、深浅两套主题走过 17 个页面；真实浏览器实测右面板拖动 `body.resizing-x` + `transition-duration: 0s`，切主题时卡片底色在约 220ms 内从 244,236,216 过渡到 26,23,18。发布流水线会再完整跑一次质量门。
