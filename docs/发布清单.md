# 发布清单（Release Checklist）

> 2.0 之前的快速节奏里，同日 --clobber 重传、版本号重排、更新链路断裂（1.7 引入、1.9 才修好）
> 各发生过至少一次。从 2.1.0 起按本清单发版：**每条都要打勾，同日不二次发版，目标双周一版。**

## 1. 版本号一致（四处）

- [ ] `engine/pyproject.toml` 的 `version`（semver 三段式，如 `2.1.0`）
- [ ] `engine/src/skysheep/__init__.py` 的 `__version__`（与上完全一致）
- [ ] `engine/tools/installer.iss` 的 `#define MyAppVersion`（决定安装包文件名）
- [ ] `CHANGELOG.md` 顶部新条目（版本号 + 日期）

## 2. 质量门

- [ ] `uv run pytest` 全量通过（含覆盖率门）
- [ ] `uv run pytest -m e2e` 单独通过（真实 socket 用例）
- [ ] `uv run ruff check .` 无告警
- [ ] 冒烟：`uv run skysheep app` 起得来、发一轮消息、设置页能打开

## 3. 打包与安装包

> 本节可用 `engine/tools/release.py` 一键执行（依赖同步→打包→产物校验→冒烟→安装包→sha256；
> 默认只做本地构建，`--upload` 才上传，见 §4）。

- [ ] PyInstaller 已入册 dev 组（pyproject/uv.lock 锁定版本）：`uv sync` 即装，
      `uv run` 不再按 lock 修剪它；刚拉取代码先 `uv sync --locked` 对齐环境
- [ ] 打包/冒烟**不经 `uv run`**，直接用 `.venv\Scripts\pyinstaller.exe --noconfirm --clean SkySheep.spec`
- [ ] 冒烟产物 `engine/dist/SkySheep/SkySheep.exe`：启动、对话、设置、终端面板各点一遍
- [ ] ISCC 编译安装包：`D:\Inno Setup 7\ISCC.exe engine\tools\installer.iss`
      产物 `engine/installer/SkySheep-<版本>-setup.exe`（文件名由 MyAppVersion 决定）
- [ ] 安装包本机装机冒烟：装完能启动、能卸载；应用运行中卸载应被拒绝（互斥体）

## 4. 发布与更新链路

- [ ] git tag `v<版本>`（如 `v2.1.0`）；更新检查按 tag 数字段比较（`core/uptodate.py`），tag 必须是 `v` 前缀 + 数字段
- [ ] GitHub Release 资产名必须是 `SkySheep-<版本>-setup.exe`——应用内更新按这个约定拼下载地址，名字对不上更新就是坏的
- [ ] **不 --clobber 重传**：资产传错就删掉重传同名新文件；发现版本号错一律改号重发，不同日重发同一版本
- [ ] Release 正文：把 CHANGELOG 条目的**手动换行并回长句**（GitHub release 页把单个换行渲染成真换行，照搬源码每行只显示半截）
- [ ] **生成并上传 `<安装包名>.sha256` 校验附件**：`Get-FileHash engine\installer\SkySheep-<版本>-setup.exe -Algorithm SHA256`，
      把十六进制哈希写进同名附件 `SkySheep-<版本>-setup.exe.sha256`（内容就是 64 位哈希值，
      可带 `  <文件名>` 尾巴），**作为 Release 资产与安装包一并上传**——应用内更新链路只按
      「安装包名 + .sha256」同目录探测校验和（`engine/src/skysheep/server/backend_parts/remote.py`
      的 `_fetch_setup_sha256`），不传这个附件，应用内的「校验通过」就永远是假；
      Release 正文末尾同时贴一份可读哈希（`docs/smartscreen-说明.md` 的「校验安装包」一节承诺
      Release 附带校验值，用户照它自查比对）
- [ ] 发布后验证：`https://github.com/<org>/<repo>/releases/latest` 302 到新 tag；资产下载链接 200
- [ ] 装旧版本的应用内「检查更新」能识别新版本、能下载、静默安装日志 `~/.skysheep/logs/update-setup.log` 退出码为 0

## 5. 文档同步

- [ ] `README.md` 与 `README.en.md` 一致：安全机制条数（当前 12）、能力对照表行数（当前 29）、被砍/新增功能
- [ ] 两份 README 路线图的「✅ 当前版本」标记指向 CHANGELOG 最新发布条目（CI 由
      `engine/tools/check_versions.py` 机械校验，版本漂移直接红）
- [ ] `index.html`（落地页）功能卡与实际功能面一致：2.0 上线的记忆地图曾六个版本没上过落地页
- [ ] 安装包被 SmartScreen 拦截的指引仍在：`docs/smartscreen-说明.md`
- [ ] 新增设置项都有「读回 → 编辑 → 保存热生效」路径，没有让用户手改 config.toml 的说明

## 6. 历史包袱（发布前自查）

- [ ] 上一版的本地安装包移入 `归档/安装包历史-已下架/`（上级目录，加日期后缀区分同名）
- [ ] `engine/installer/` 里只留现版与上一版（更早的进归档，避免误传成 Release 资产）
