# 远程访问安全说明

SkySheep 的「局域网访问」与「远程访问（Tailscale）」让你用手机 / 平板打开完整界面遥控这台电脑。
本文汇总这条链路的安全边界与使用建议。

## 两条通道

| | 局域网访问 | 远程访问（Tailscale） |
|---|---|---|
| 适用 | 同一 Wi-Fi 下的设备 | 任意网络（含手机流量） |
| 传输 | **http 明文** | Tailscale 虚拟网内端到端加密 |
| 谁能连 | 同一网段的所有设备（凭令牌） | 登录你 Tailscale 账号的设备（凭令牌） |
| 地址 | `http://<本机 IP>:<端口>/?token=…` | `http://<100.64.x.x>:<端口>/?token=…` |

两者共用同一把访问令牌，同一时间只会启用其中一种（或都关）。

## 令牌就是钥匙

- 令牌由 `secrets.token_urlsafe(16)` 生成（128 bit 熵）；也可以自定义，但最短 12 位且有字符多样性校验。
- 令牌加密存放于本机 `config.toml`（Windows 上经 DPAPI 加密），界面只显示打码片段。
- **令牌泄露 = 完整控制权**：拿到令牌的人可以聊天、读写本机文件、执行命令（写/执行仍会弹确认，但确认卡是发到对方屏幕上的）。
- 泄露后的处置：设置 → 手机控制 → **重新生成令牌**，旧令牌与已登录设备的 cookie 立即作废。

## 已知暴露面与对应建议

1. **URL 查询参数传令牌**：首次访问的地址与二维码里含明文令牌（`?token=…`），成功后浏览器会种一个 30 天的 cookie，之后不再需要拼参数。注意：
   - 二维码 / 地址不要截图外传；
   - 浏览器历史里会留下带令牌的地址，公共设备上使用后建议清历史；
   - 令牌轮换后，历史里的旧地址自动失效。
2. **局域网是 http 明文**：同一网络中的其他设备可以在链路上嗅探到流量（包括令牌与对话内容）。**只建议在可信网络使用**；咖啡馆 / 酒店 Wi-Fi 请改用 Tailscale。
3. **局域网模式下的防火墙**：首次开启后 Windows 会弹授权框，需要点「允许」；否则手机连不上。
4. **失败留痕**：连续多次令牌验证失败会自动限流（同 IP 5 次失败封 30 秒，指数退避封顶 10 分钟），设置页可见失败次数与来源，明显异常时建议轮换令牌。
5. **已连接设备可查可断**：设置 → 手机控制里列出当前在线的远程设备（IP / 来源 / 连接时间），可一键断开；断开后对方需重新打开地址（重新验令牌）。

## 传输加密的正路

SkySheep 自身不提供 HTTPS。跨不可信网络使用时，推荐 **Tailscale**：链路加密、设备级准入（只有你账号里的设备能连），并且不依赖局域网是否可信。
