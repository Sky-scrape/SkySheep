              等工具已装在本机的技能，勾选即可复用，装完立即生效。

              下面两个总开关默认关闭，打开后对应工具才会出现在列表里（打开即生效）。

                  基础设置
                  
              
            
                  
            
                  
              子代理是 Agent 派出去的「分身」：调研、后台跑任务可以并行做，不挤占主对话。
              关闭后 Agent 只用主对话逐步处理；开启后还可限制每个分身最多干多少轮。
            
                  
            
                  
            
                  
          
                  

          
                  
            
                  
              
                  自定义子代理
                  
              
            
                  
            
                  
              给特定任务定制「分身」：起个名字、写清楚它负责什么、给它专项指令，再挑一套工具和模型。
              保存后 Agent 在合适的任务里会自动派它出场（对话里也可以点名让它用）。
              注意：无论给多少工具，子代理里的写入 / 执行操作仍会被自动拒绝——需要确认的操作由主 Agent 来做。
            
                  
            
                  
            
                    
          
                    

          
                    
            
                    内置子代理
                    
            
                    
              general-purpose 负责多步通用任务，Explore 专做只读调研。
              可以为它们单独指定模型和思考强度；留空（跟随主对话）就用当前对话的模型。
            
                    
            
                    
            
                      
          
                      
        
                      

        
                      
          
                      
            
                      
              
                      MCP 服务
                      
              
                
                
              
            
                      
            
                      
              MCP 让 Agent 接入外部工具（浏览器、数据库、办公软件…）。
              下面一排是内置常用服务，点「＋ 添加」即接入并即时可用；
              也可「导入配置」粘贴一段 MCP 配置（Claude Desktop 的 mcpServers 格式）或选一个 .json 文件，
              「手动添加」逐个填。改完立即生效、不用重启。
            
                      
            
                      
            
                      
            
                        
          
                        
        
                        

        
                        
          
                        
            
                        
              
                        本项目白名单
                        
              
                
                
                
                
              
            
                        
            
                        
              你在对话中选择「总是允许」时保存的规则；删除后对应操作会重新询问。
                        
              命令的前缀规则不会命中带 shell 拼接的命令（如 git status; rm -rf /）——
              这类命令每次都重新询问，要放行它请选择「允许一次」；键盘的「总是允许」只固化那一次
              输入的内容/键位（内容不同的输入仍需确认）。「允许访问哪些目录」是另一层限制，
              在 高级 · 安全与后台 里设置。

                          钩子（Hooks）
                          
              
            
                          
            
                          
              在 Agent 每次调用工具的前 / 后自动跑一条你自己的命令。典型用途：写入前先跑
              格式检查、跑完命令弹个提醒、把关键操作记进自己的日志。
              前钩子可以阻挡这次调用：退出码 2（或输出 {"decision":"block"}）就拦下，
              标准错误会作为原因告诉 Agent。例如 match 填 write_file、
              命令填 python check.py：脚本退出码为 2 时，这次写入就会被拦下。
            
                          
            
                          
              命令会把一份 JSON 从标准输入交给你的程序：
              {"tool": "write_file", "input": {...}, "working_dir": "..."}。
              命令来自你自己的配置，等价于你手敲，不经过权限确认——请只填可信的命令。

                          安全与后台
                          
            
                          
              这些开关影响 Agent 能碰什么、以及它能自己醒着干活的范围。
            
                          
            
            
                          
              开启后，读写工作目录以外的文件会被直接拒绝（包括 @ 引用的外部文件）。
              只读工具平时是自动放行的，这个开关给"只看这一个项目"上把锁。
            
                          
            
                          
              关闭时（默认），只读工具（读文件 / 列目录 / 搜索）可以不经确认读取磁盘上
              任何位置——包括 ~/.ssh 下的私钥、浏览器数据。如果 Agent 会被诱导
              读入外来的网页或文件内容，建议开启这个开关。
            
                          
            
                          
              
              读取中…
            
                          
            
                          
              项目目录下的 .skysheep/（mcp.json 与 skills/）是随仓库一起分发的数据，
              首次打开时会先问一句是否信任，确认前不会执行其中的命令、也不会把技能拼进系统提示词。
              信任按项目记忆，配置内容一变就需要重新确认；全局配置不受影响。
            
                          
            
            
                          
          
                          
        
                          

        
                          
          
                          
            
                          远程控制
                          
            
                          
              把 SkySheep 接到别的设备上用：手机 / 平板扫同一 Wi-Fi 或经 Tailscale
              跨网络打开完整界面，或在 Telegram / 微信里给机器人发消息遥控。
              这些能力默认全部关闭，需要时逐项打开。
            
                          
          
                          
          
                          
            
                          手机控制
                          
              
            
                          
            
                          
              用手机遥控这台电脑上的 SkySheep：开启后（重启 SkySheep 生效），同一 Wi-Fi 下的
              手机 / 平板扫码或输入地址，即可打开完整界面——继续聊天、批准确认、看任务进度，
              电脑端同步可见。服务将对局域网开放，令牌即密码，请勿在公共网络使用；关闭后恢复仅本机访问。
            
                          
            
                          
          
                          
          
                          
            
                          远程访问（Tailscale）
                          
              
            
                          
            
                          
              不在同一 Wi-Fi（手机开流量也行）也能连回家里的 SkySheep：电脑和手机都安装
              Tailscale（tailscale.com）并登录同一账号，这里开启后（重启 SkySheep 生效），
              手机在任意网络打开电脑的 Tailscale 地址，就能用完整界面继续聊、批准确认、看任务进度。
              链路经 Tailscale 端到端加密，访问令牌与「手机控制」共用；未装 Tailscale 的设备
              （包括同一 Wi-Fi 下的）反而连不进来。
            
                          
            
                          
          
                          
          
                          
            
                          聊天机器人渠道
                          
            
                          
              把 Telegram / 微信 接成遥控端：在手机上给机器人发消息，就能让这台电脑上的
              SkySheep 干活，回复直接回到聊天窗口。渠道默认关闭；启用前必须先把你的账号加入
              允许名单——没有名单的机器人等于对所有人开放，而知道机器人账号的人都能给它发消息。
              「允许操作」未开启时，机器人只能读不能写（改文件、跑命令一律自动拒绝）。
              Telegram 需自备 Bot Token；微信无需 Token，扫二维码登录即可。
            
                          
            
                          
          
                          
        
                          

        
                          
          
                          
            
                          
              
                          全局记忆
                          
              
            
                          
            
                          
              跨项目生效的用户记忆：Agent 对话中说「记住我喜欢…」时会自动写进来（格式为
              - [日期] 内容 的列表），每一轮对话都会注入。这里可以直接查看、修改；
              保存后对所有会话立即生效。与之相对，「项目记忆」只对当前项目生效，
              在对话窗口右侧面板的「记忆」页签里查看和编辑。
            
                          
            
                          
            
          
                          
          
                          
            
                          自动记忆与整理
                          
            
                          
              归档提炼：归档会话时，后台用当前模型通读这段对话，把值得长期记住的信息
              （偏好、常用环境、做事约定；不含一次性任务细节与机密）自动提炼进上面的全局记忆，
              最多 8 条、与已有记忆重复的自动跳过，提炼完成会通知你记住了什么。
              额外消耗一次模型调用；寒暄、单条短问答不会触发。
            
                          
            
                          
              定期整理：按周期用当前模型通读记忆，合并重复、相似或过时的条目，
              让记忆越用越精炼而不是越攒越长。整理前自动把原件备份为 .bak 文件（同目录），
              整理完成后会通知你。全局记忆不足 400 字时自动跳过、不花模型调用；
              项目记忆（AGENTS.md）的整理开关在右侧面板的「项目记忆」页签最上方。

                            数据与隐私
                            
            
                            
              SkySheep 是纯本地应用：会话记录、配置、API Key 全部只保存在你自己的电脑上，不经过任何第三方服务器。以下是你本机的数据位置。
            
                            
            
                            
            
                            
              
              
              
              
              
            
                            
          
                            
          
                            
            
                            
              
                            会话库备份
                            
              
            
                            
            
                            
              每次启动前都会给会话数据库留一份备份（保留最近 20 份）；误删会话、或数据不对劲时，
              在这里挑一个较早的版本恢复即可。下方默认只列最近几份，点「展开」看全部。
