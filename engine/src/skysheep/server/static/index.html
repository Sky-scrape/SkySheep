            模型服务
            
              
            
            

            
            
            
              
            
                点是哪一行就进哪个服务的配置。★ 是启动默认模型，「使用中」是当前对话所用模型。
                列表里没有的服务（自建中转、公司内网、其他厂商）用右上角按钮自己添加；
                用不到的进它的配置里点「删除」即可移出列表（内置服务删掉后可随时恢复）。
              
            
              
            
              
            
              
            
            
            

            
            
            
              
            
                
                
              
            
              
            
              
            
            
            
          
            
        
            

        
            
          
            
            
            
              
            技能
            
              
                
                
              
            
            
            
            
              技能是写给 Agent 看的「操作手册」：启用后相关用法会进入系统提示词，Agent 会在合适的任务里自动套用。
              点右上角「导入技能」：可以选本机的技能文件夹或 .zip 压缩包，也可以直接粘贴
              GitHub / Gitee 仓库链接在线安装，装完立即生效。「技能广场」里有精选技能可一键安装。

              内置工具
              
            
              
              Agent 完成任务时可以调用的工具。只读操作自动放行；写入与高危（执行命令）操作默认会先征得你确认。
            
              
            
                
          
                
        
                

        
                
          
                
            
                
              
                基础设置
                
              
            
                
            
                
              子代理是 Agent 派出去的「分身」：调研、后台跑任务可以并行做，不挤占主对话。
              关闭后 Agent 只用主对话逐步处理；开启后还可限制每个分身最多干多少轮。
            
                
            
                
            
                
          
                

          
                
            
                
              
                自定义子代理
                
              
            
                
            
                
              给特定任务定制「分身」：起个名字、写清楚它负责什么、给它专项指令，再挑一套工具和模型。
              保存后 Agent 在合适的任务里会自动派它出场（对话里也可以点名让它用）。
              注意：无论给多少工具，子代理里的写入 / 执行操作仍会被自动拒绝——需要确认的操作由主 Agent 来做。
            
                
            
                
            
                  
          
                  

          
                  
            
                  内置子代理
                  
            
                  
              general-purpose 负责多步通用任务，Explore 专做只读调研。
              可以为它们单独指定模型和思考强度；留空（跟随主对话）就用当前对话的模型。
            
                  
            
                  
            
                    
          
                    
        
                    

        
                    
          
                    
            
                    
              
                    MCP 服务
                    
              
                
                
              
            
                    
            
                    
              MCP 让 Agent 接入外部工具（浏览器、数据库、办公软件…）。
              下面一排是内置常用服务，点「＋ 添加」即接入并即时可用；
              也可「导入配置」粘贴一段 MCP 配置（Claude Desktop 的 mcpServers 格式）或选一个 .json 文件，
              「手动添加」逐个填。改完立即生效、不用重启。
            
                    
            
                    
            
                    
            
                      
          
                      
        
                      

        
                      
          
                      
            
                      本项目白名单
                      
            
                      
              你在对话中选择「总是允许」时保存的规则；删除后对应操作会重新询问。
            
                      
            
                        
          
                        
        
                        

        
                        
          
                        
            
                        
              
                        运行参数
                        
              
            
                        
            
                        
              这些参数平时不用动。Agent 干到一半自己停下（轮数用尽）、或者长对话总是在快要压缩时卡住时，再来调。
            
                        
            
                        
            
                        
              
                        
                
                
                默认 40。Agent 调工具一次算一轮；复杂任务可调到 60–80
              
                        
              
                        
                
                
                
              
                        
              
                        
                
                
                默认 8。自动压缩历史时，最近这么多条原样保留
              
                        
              
                        
                
                
                0 = 不限制。当天累计用量达到上限后不再发送新消息，明天自动重置
              
                        
            
                        
          
                        

          
                        
            
                        安全与后台
                        
            
                        
              这些开关影响 Agent 能碰什么、以及它能自己醒着干活的范围。
            
                        
            
            
                        
              开启后，读写工作目录以外的文件会被直接拒绝（包括 @ 引用的外部文件）。
              只读工具平时是自动放行的，这个开关给"只看这一个项目"上把锁。
            
                        
            
            
                        
              让 Agent 能「看见并操作」你的桌面：截屏进对话、移动鼠标、输入文字。
              高危操作逐次确认，可按动作加白名单。默认关闭——普通用户用不到，
              有「帮我操作这个软件」这类需求时再打开。保存后立即对所有会话生效。
            
                        
            
            
                        
              让 Agent 能用你的默认浏览器打开网址或搜索关键词（比如「帮我打开这个链接」
              「搜一下最近的新闻给我看」）。页面在你的浏览器里打开，逐次确认，
              可按动作加白名单；默认关闭。Agent 自己读网页内容不受此开关影响（web_fetch）。
            
                        
            
            
                        
          
                        
        
                        

        
                        
          
                        
            
                        
              
                        全局记忆
                        
              
            
                        
            
                        
              跨项目生效的用户记忆：Agent 对话中说「记住我喜欢…」时会自动写进来（格式为
              - [日期] 内容 的列表），每一轮对话都会注入。这里可以直接查看、修改；
              保存后对所有会话立即生效。与之相对，「项目记忆」只对当前项目生效。
            
                        
            
                        
            
          
                        
        
                        

        
                        
          
                        
            
                        主题
                        
            
                        
              「跟随系统」按 Windows 的深浅色自动切换；标题栏颜色会一起变。
            
                        
            
                        
              
              
              
            
                        
          
                        
          
                        
            
                        📱 手机控制
                        
              
            
                        
            
                        
              用手机遥控这台电脑上的 SkySheep：开启后（重启 SkySheep 生效），同一 Wi-Fi 下的
              手机 / 平板扫码或输入地址，即可打开完整界面——继续聊天、批准确认、看任务进度，
              电脑端同步可见。服务将对局域网开放，令牌即密码，请勿在公共网络使用；关闭后恢复仅本机访问。
            
                        
            
                        
          
                        
          
                        
            
                        Windows 系统通知
                        
            
                        
              窗口失焦时，任务完成、Agent 等待确认会弹系统通知；前台使用时不打扰。
              无人值守的定时任务结果也会通知。
            
                        
            
          
                        
          
                        
            
                        对话区宠物
                        
            
                        
              聊天流右下角的「云朵小羊」：Agent 干活时它会蹦跶，等待你确认时摇晃提醒，点它会跟你打招呼。
            
                        
            
          
                        
          
                        
            
                        界面缩放
                        
            
                        
              在左侧边栏底部的「界面 −/+」控件随时调整整个界面的显示大小（70%–120%，步长 10%），
              字体随内容一起缩放，偏好自动保存。
            
                        
          
                        
        
                        

        
                        
          
                        
            
                        
              
                        快捷指令
                        
              
            
                        
            
                        
              常用的提示词模板。在输入框输入 / 时会出现在候选最上方，选中即插入到输入框。
              内容里的 {{clipboard}} 会在插入时替换为当前剪贴板文本。

              （输入价 / 输出价，单位：元），保存后这里会显示估算费用。

                          关于
                          
            
                          
            
                          
          
                          
          
                          
            
                          数据与隐私
                          
            
                          
              SkySheep 是纯本地应用：会话记录、配置、API Key 全部只保存在你自己的电脑上，不经过任何第三方服务器。以下是你本机的数据位置。
            
                          
            
                          
            
                          
              
              
              
              
              
            
                          
          
                          
          
                          
            
                          
              
                          会话库备份
                          
              
            
                          
            
                          
              SkySheep 每次启动前都会给会话数据库留一份备份（保留最近 20 份）。
              误删了会话、或数据不对劲时，可以在这里挑一个较早的版本恢复。
              恢复会用备份整体替换当前数据，所以恢复前系统会自动把现状另存一份，随时能换回来。
            
                          
            
                          
            
                            
          
                            
          
                            
            
                            设置导出 / 导入
                            
            
                            
              把模型服务（含 API Key）、MCP 配置、界面偏好、全局记忆打包成一个 zip，
              在另一台电脑上导入即可完成迁移。会话记录不包含在内。
