反馈问题
SkySheep 免费吗？需要账号吗？

SkySheep 以 MIT 协议开源，无需注册 SkySheep 账号。使用云端模型时，需要提供所选服务的 API Key，费用由该服务收取；也可连接本地推理服务。演示模式无需 API Key，但不是免费的真实模型服务。

和普通聊天客户端有什么不同？

SkySheep 不只生成回答，还能调用工具读写文件、执行命令、处理文档和操作电脑。权限确认、文件改动、终端输出与任务进度都在图形界面里，多模型协作与自动化也是原生功能。

我的数据会离开电脑吗？

会话、配置与密钥保存在本机，SkySheep 无遥测。但云端模型需要接收请求中的上下文，联网工具也会联系外部服务。要在本地处理，请选择本地推理服务，并根据需要限制联网工具；不要把“本机存储”理解成“所有请求都不联网”。

它做的所有操作，都能撤销吗？

不能。受支持的文件操作会记录检查点，可使用“撤销本轮改动”恢复。执行命令、电脑控制，以及外部服务上的操作可能产生不可回滚的副作用；确认前请查看操作范围与可撤销性，不要未经核对就放宽权限。

支持 macOS、Linux 或手机吗？

当前受支持的产品形态是 Windows 10 / 11 x64 桌面应用。手机可通过远程访问打开网页界面，不是独立原生 App。macOS / Linux 上的 --browser 是开发者兜底路径，不在桌面支持承诺内。

开发者怎么从源码运行？

需要 Python ≥ 3.11 与 uv。Windows 为支持平台；启动后按向导配置模型。以下命令只安装并启动项目，不涉及你的真实会话数据管理。

在终端运行
git clone https://github.com/Sky-scrape/SkySheep.git
cd SkySheep/engine
uv sync
uv run skysheep app
