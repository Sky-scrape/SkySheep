# 上下文天气（token-weather）

SkySheep 官方示例 Mod（实验性）。把上下文占用做成天气式的常驻状态条，显示在输入区右侧：

- ☁️ **晴**：占用 < 60%
- 🌫 **多云**（黄）：占用 60–84%
- ⛈ **风暴**（红）：占用 ≥ 85% —— 该执行 `/compact` 压缩历史了

## 工作方式

- 挂在 `tool_post`（节流 2 秒）与 `turn_stop` 两个事件上，只观察、不干预；
- 数据是引擎附带的真实 token 统计与当前模型的上下文上限，状态按会话分开记忆；
- `permissions: "observe"`——本 Mod 没有任何拒绝/放行能力，也不修改任何参数。

## 定位

对位 Claude Code Mods 生态里的 Token Weather：演示第三方 Mod 如何在原生界面
（上下文容量环形仪表）之外补充同构的展示，且完全不碰引擎内部状态。
