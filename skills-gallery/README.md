# skills-gallery — 官方种子技能包

SkySheep 自带的官方技能集，面向中文场景：写周报、整理会议纪要、清洗 Excel、做旅行攻略……
每个技能是一个文件夹，里面一个 `SKILL.md`（frontmatter 声明 `name` 与 `description`，正文是注入给模型的执行指引）。

## 技能清单

| 技能 | 文件夹 | 用途 |
| --- | --- | --- |
| 周报生成 | `weekly-report/` | 汇总本周工作，四段式中文周报，可存 docx |
| 会议纪要 | `meeting-notes/` | 转写/速记/聊天记录 → 结论、决议、行动项 |
| 公众号文章写作 | `wechat-article/` | 选题 → 大纲 → 成稿的新媒体文案 |
| Excel 清洗与报表 | `excel-clean/` | 去重补空、统一格式、拆分列，产出干净表格 |
| 简历优化 | `resume-polish/` | 对照 JD 逐条对齐，产出优化版 docx |
| 长文档精读 | `doc-digest/` | 一页速览 + 逐章展开，要点带页码 |
| 旅行规划 | `travel-planner/` | 实时检索 + 按天行程表 + 预算估算 |
| 一周菜谱与采购清单 | `meal-plan/` | 七天三餐菜谱 + 分类采购清单（xlsx） |
| 英文邮件润色 | `english-email/` | 三种语气版本 + 用词解释 |
| 目录文件整理 | `file-tidy/` | 先审方案再移动文件，整理完留报告 |

## 安装

**方式一：技能广场一键安装（推荐）**
打开 SkySheep → 设置 · 技能与工具 → 点「技能」卡片进独立技能页 → 展开「技能广场」，
在搜索框输入技能名（或用途关键词，
如「文档 分析」）缩小范围，找到对应技能点「安装」即可，无需手动操作。

**方式二：手动安装**
把技能文件夹整个复制到用户技能目录：

```
~/.skysheep/skills/<技能名>/SKILL.md
```

Windows 下即 `C:\Users\<你>\.skysheep\skills\`。复制后在 设置 · 技能与工具 里启用即可。

## 贡献

欢迎补充新技能，直接向本目录提 PR：

1. 新建文件夹 `your-skill-name/`（kebab-case，与 `name` 字段同名），内放 `SKILL.md`；
2. frontmatter 必须包含 `name` 与 `description`（中文一句话，100 字内，会展示在技能广场卡片上）；
3. 正文写成给模型看的执行指引：说清步骤、用哪些内置工具、输出格式与注意事项；涉及写文件、执行命令的操作必须提示「先经用户确认」；
4. 提交前自测：技能能被 SkySheep 发现并启用，按正文指引跑通一次完整流程。

优质技能会被收录进 `market/index.json` 的技能广场索引，让所有用户一键安装。
