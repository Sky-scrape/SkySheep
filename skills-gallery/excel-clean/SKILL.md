## 目标

把一份「脏」的 .xlsx / .csv 表格清洗成可直接使用的数据：重复行去掉、空值处理好、格式统一、字段拆分到位，并交代清楚每一处改动，保证可追溯。

## 使用时机

- 用户说「帮我清洗这份数据」「这个表太乱了」「去掉重复行 / 统一格式」。
- 用户给出 .xlsx / .csv 文件，希望整理成规范表格或用于汇报。

## 执行步骤

1. **读表**：用 `read_document` 读取用户指定的 .xlsx 或 .csv 文件，先摸清结构：有几张工作表、表头在哪一行、各列含义、数据类型、大致行数。
2. **报告问题**：在对话里列出发现的数据问题，例如——
   - 完全重复的行 N 条；
   - 关键列空值 M 处（指出哪些列）；
   - 格式混乱：日期写法不一（2024/1/1、2024-01-01、1月1日）、金额带「¥」和千分位、手机号被存成科学计数法、多余空格、全半角混用；
   - 该拆的列：如「省-市-区」挤在一列、姓名和手机号在一格。
3. **确认规则**：把清洗方案讲给用户听并逐项确认，尤其是需要替用户做决定的——空值是填 0、填均值、填「未知」还是整行删除？异常值（如年龄 300、日期在 1970 前）是修正、标记还是剔除？**没有用户确认不要自作主张删数据。**
4. **执行清洗**：在内存中按确认的规则处理，整理出干净表格。
5. **产出文件**：与用户确认文件名和保存位置后，用 `write_document` 生成清洗后的 .xlsx（保留原表头，工作表命名为「清洗后」）。
6. **附清洗说明**：用 `write_file` 在同目录生成一个简短的 Markdown 说明，逐条记录做了什么改动、影响多少行，方便用户回溯。

## 输出格式

清洗完成后回复用户：

```markdown
## 清洗完成

**结果文件**：<路径>/xxx_clean.xlsx

**清洗说明**：
1. 去重：删除完全重复行 N 条，剩余 X 行；
2. 补空：<列名> 空值 M 处，按 <规则> 处理；
3. 格式统一：日期统一为 YYYY-MM-DD，金额统一为两位小数数值；
4. 拆分列：「地址」拆为省 / 市 / 区三列。

**遗留问题**：<无法自动处理、需人工复核的行，说明行号和原因>
```

## 注意事项

- 只用 `read_document` 读表、`write_document` 写表；不要虚构表格里不存在的数据，补空的规则必须来自用户确认。
- 删除类操作（去重、剔行）执行前必须报告影响行数并获用户同意。
- 原始文件只读不改；清洗结果写入新文件，文件名建议加 `_clean` 后缀。
- 涉及个人信息（身份证、手机号、住址）时提醒用户注意脱敏与保存范围。
- 大表（上万行）先抽样确认规则再全量处理，避免规则错了返工。

## 常见问题

- 用户说不清规则：先按「最小侵入」给默认方案——只去完全重复、空值仅标记不填、格式统一但保留原值列，跑一小版样例给用户看。
- 多张工作表：逐张确认结构是否一致，合并前先把对齐结果给用户过目。
- 数字被存成文本：转换前抽样验证，转换失败的行列入「遗留问题」，不硬转不丢行。
- 清洗后还要继续分析（求和、透视）：问清统计口径再动，避免口径不一致白做。
- 文件里有公式或合并单元格：提醒清洗副本会变成纯值，原文件保持不动。
- 用户后续要按月追加数据：问清是否会重复清洗，建议把本次规则写成固定清单（`write_file` 存档），下月照单执行。
- 表头不在第一行：先定位真实表头行，再按该行确定列名，不要把说明行当数据。
- 出现「合计」「总计」行混在数据里：单独剥离出来，避免参与去重和统计。
- 同一列混有多种类型（文本夹数字）：先给用户看混型样例，确认统一方向后再转。
