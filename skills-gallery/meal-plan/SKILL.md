## 目标

帮用户解决「这周吃什么」：排出营养均衡、操作量符合家庭实际的一周三餐菜谱，并自动汇总成按类别分组、按超市动线排序的采购清单，买菜时不来回跑。

## 使用时机

- 用户说「帮我排个一周菜谱」「这周吃什么」「列个买菜清单」。
- 用户想控预算、控热量或解决「每天做饭没思路」的问题。

## 执行步骤

1. **问清约束**：
   - 用餐人数与构成（成人 / 孩子 / 老人），几人在家吃晚餐；
   - 忌口与过敏（辣度、素食、不吃香菜、花生过敏等）；
   - 厨艺与设备：会做硬菜吗？有没有烤箱 / 空气炸锅？
   - 每天做饭时间预算（工作日 30 分钟内还是可以慢慢做）；
   - 是否需要控热量 / 控预算，有没有想清空的库存食材。
2. **排菜谱**：一周 7 天 × 早 / 中 / 晚。排菜原则——
   - 晚餐按「一荤一素一汤」或「两荤一素」搭配，红烧类、清炒类、蒸菜交替不重样；
   - 食材复用：买一次的肉分两顿不同做法，减少浪费；
   - 工作日排快手菜（30 分钟内），周末排硬菜；
   - 早餐兼顾快（鸡蛋、粥、面点轮换），午餐按带饭场景给「隔夜也好吃」的菜；
   - 严格遵守忌口与过敏限制，过敏项一律不出现。
3. **汇总采购清单**：把菜谱里所有食材归并（同食材多菜合计算量），按「蔬菜 / 肉蛋 / 水产 / 主食粮油 / 调料 / 其他」分类，每项标注估算用量。调味料先问用户家里已有哪些，只补缺的。
4. **产出文件（可选）**：与用户确认文件名和位置后，用 `write_document` 生成 .xlsx：工作表 1 为「一周菜谱」（行=天数，列=三餐），工作表 2 为「采购清单」（分类 / 品名 / 用量 / 已备勾选列）。写文件会弹确认框，属正常流程。

## 输出格式

对话里的菜谱速览：

```markdown
## 一周菜谱速览
| 天 | 早餐 | 午餐 | 晚餐 |
| --- | --- | --- | --- |
| 周一 | ... | ... | ... |

## 采购清单
**蔬菜**：西红柿 6 个、西兰花 2 颗……
**肉蛋**：鸡蛋 20 个、猪里脊 500g……
（其余分类同）

## 小提示
- <提前一晚要做的准备：腌肉、泡发、解冻>
```

## 注意事项

- 排菜谱前必须确认忌口和过敏；过敏食材零容忍，即使用户后面没再提。
- 用量按人数估算并说明是估算值，用户按家人口量微调即可。
- 不推荐需要罕见厨具或高超技巧的菜，除非用户表明厨艺娴熟。
- 提示生熟分开、肉类冷藏解冻等基本食品安全要点，一条即可不必说教。
- 生成 xlsx 前与用户确认文件名与保存位置。

## 常见问题

- 家里已有存货：请用户报库存，先安排「清库存菜」，采购清单相应剔除已有项。
- 一周后想换口味：保留框架只换菜名，蛋白质和烹法轮换（红烧换清蒸、炒换炖）即可出新。
- 有减脂 / 增肌需求：按热量思路调整主食与蛋白比例，具体营养方案提醒咨询专业人士。
- 临时要招待客人：从本周菜谱挑升级组合（加一道硬菜一道汤），单独给采购增补项。
