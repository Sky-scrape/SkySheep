## 目标

给跑了一段时间的团队做一次体检：工单吞吐多少、卡在哪、谁超时、打回了几次、未尽事项攒了哪些——一页摘要说清「团队这周跑得怎么样，下周怎么调」。

## 使用时机

- 用户说「巡检一下团队」「团队这周跑得怎么样」「给团队做个体检」「看看工单板」。
- 用户想每周固定巡检一次团队运行，产出留档摘要。

## 执行步骤

1. **定范围**：确认巡检哪个项目、时间窗（默认近一周）。团队运行的落盘痕迹在 `<项目>/.skysheep/reports/`（工作区即项目目录）；其他项目的团队请切到那个项目再巡检。
2. **收材料**（只读读取，自动放行）：
   - `cron-team-*.md`——定时团队的交付说明全文，是巡检主材料。头部元信息块有任务名、模板名、触发方式、终态、轮次消耗、**工单板快照**、逐成员与总管用量；
   - `team-*.md`——团队频道的长文落盘（超长频道消息的全文），看队员实际回报质量用，交互式与定时团队都可能产生；
   - 注意滚动清理：`team-*.md` 按数量与总字节从旧到新清理（`cron-team-*.md` 不受清理），旧材料可能已不在盘上，摘要里如实注明统计覆盖到的最早时间。
3. **对齐工单板口径**：工单五态——待处理 / 进行中 / 待验收 / 已完成 / 出错；每张工单带负责人与打回次数。快照里逐单数，不凭印象。
4. **算体检指标**（只从材料里数，缺材料就写「无材料」，不估数）：
   - **吞吐**：已完成工单数；每次运行的轮次消耗（用了多少 / 上限 40）；
   - **卡单**：停在「进行中 / 待验收」的工单；出错工单及其原因；
   - **质量**：被打回（打回次数 ≥1）的工单占比；终态分布——正常交付 / 轮次耗尽 / 预算越线 / 中止（轮次耗尽与预算越线是设计内停机，按「上限偏紧」解读，不当故障）；
   - **负载**：逐成员用量与工单分布，谁长期满载、谁闲置；
   - **沟通**：频道长文里 @总管裁定、开小会的痕迹，回报是否带出处。
5. **产出体检摘要**：按下面输出格式组织，先在对话里呈现，等用户确认。
6. **归档（可选）**：用户要留档时，先确认文件名与保存位置再写入（写文件走权限确认）；或建议配成每周定时任务——任务形态选「单会话」、预授权工具不勾（巡检是只读动作）、频率选每周固定时间，任务指令写明「按 team-ticket-audit 技能执行团队工单巡检」。

## 输出格式

```markdown
# 团队工单巡检摘要（<项目> | YYYY-MM-DD ~ YYYY-MM-DD）

## 本周速览
- <运行 N 次、工单 M 张、完成 X 张，一句话总评>

## 工单看板
| 状态 | 张数 | 说明 |
| --- | --- | --- |
| 已完成 | … | |
| 进行中 / 待验收 | … | 卡单明细与滞留原因 |
| 出错 | … | 原因与处置（改派 / 砍掉记未尽事项） |

## 轮次与上限
- <每次运行的轮次消耗与终态；触顶的运行注明是轮次、预算还是超时>

## 成员负载
- <成员名>：工单数、用量、超时 / 出错情况

## 卡单与风险
- <工单或现象>：影响、建议动作

## 改进建议
- <最多 3 条，指向可操作的变化：收窄任务指令、调预授权、改模板人设、拆小工单>
```

## 注意事项

- 巡检是只读动作：读报告目录自动放行；要写归档文件时先确认位置，写文件走确认。
- 频道消息全量落库，但回放入口在前端团队卡（team.log 按团队回放）——Agent 读不到库，要审计具体某段对话，请用户从团队卡回放后粘贴关键内容。
- 打回多、卡单多不是追责材料：给改进建议（改指令、调预授权、改人设、拆工单），不写成对某个模型成员的批评。
- 材料缺失（文件被滚动清理、运行记录只在别的项目）就注明覆盖不到，不拼凑。
- 摘要贵短：速览 1 条、改进建议 ≤3 条；看板表之外不堆明细。

## 常见问题

- 报告目录是空的：这个项目还没跑过定时团队，或团队跑在别的项目——切过去再巡检。
- 只有会话里跑过团队、没有 `cron-team-*.md`：交互式团队的交付说明在会话里，频道长文可能已有 `team-*.md` 落盘，全量频道消息用团队卡回放；请用户提供要审计的会话或回放内容。
- 用户想每天巡检：可以，但更推荐每天出值班报告（见 team-duty-report 技能）、每周巡检一次——巡检看趋势，频率太高噪音大。
- 某队员长期超时：单成员单轮有 5 分钟硬超时，先查是不是工单太大，建议拆小或换更快的模型，而不是调大上限。
- 用户想「顺手把问题修了」：巡检只出建议；改模板、改定时任务都在对应界面操作，不要代改无人值守任务的配置。
